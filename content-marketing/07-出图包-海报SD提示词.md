## 出图流程

```
1. 用 SD / ComfyUI 跑下方 prompt → 生成背景图
2. 存为 PNG，尺寸 1242×1660px（3:4 竖版，小红书最优）
3. 导入 Canva / 可画 → 叠加中文文案（下方有文案直接复制）
4. 加 YiYi英语 logo（左上角白底）
5. 底部加蓝色 CTA 条
```

## ComfyUI 工作流建议

如果使用 ComfyUI（比SD更强大）：

```
推荐工作流：
1. 加载 SD XL 1.0 base 模型
2. 节点：KSampler → VAE Decode → Image Save
3. 尺寸：832×1216（SDXL 最优竖版尺寸）
4. 然后用 Ultimate SD Upscale 放大到 1242×1660
5. Lora推荐：
   - 知识卡片风格：add_detail + flat_design lora
   - 温暖家庭场景：photorealistic_lora
```

---

## 出图后必做（Canva操作）

1. 背景图导入 Canva → 锁定图层
2. 添加文字层，字体：
   - 主标题：思源黑体 Bold，字号 56-72px
   - 正文：思源宋体 Regular，字号 28-32px
3. 底部加蓝色渐变 CTA 条（高度 120px）
4. 左上角加 YiYi英语 Logo（白底圆角，透明度80%）
5. 右下角加小字 "@YiYi英语"
6. 导出：PNG，最高质量
