## 三、爆款笔记标题公式（对标复用）

### 公式1：对比冲突型（最高点击）
```
从[A]换到[B]后，我才知道[认知颠覆]
→ "从菲教换到欧美外教后，这3件事让我后悔没早点换"
→ "从51Talk换到固定外教后，孩子不再排斥上课了"
```

### 公式2：揭秘信息差型（高转发）
```
[机构]内部价只要[价格]，[用户]都不知道
→ "YiYi英语试听课内部价：家长群才知道的优惠"
→ "欧美外教一节课不到[价格]？这个入口我藏了很久"
```

### 公式3：清单决策型（高收藏）
```
选[产品]前，这[N]个问题不问就是交智商税
→ "报英语外教课前，这5个问题不问就是浪费钱"
→ "选少儿英语机构，妈妈必须问的4个问题（附清单）"
```

### 公式4：踩坑转化型（高评论互动）
```
花了[金额]，换了[N]家后，我才[结论]
→ "花了2万，换了4家英语机构后，我才找到这家"
→ "被坑3次后，我总结了选固定欧美外教的秘诀"
```

### 公式5：孩子成果型（高分享）
```
[时间段]，孩子从[起点]到[终点]（附真实视频）
→ "3个月，我家娃从开口就哑到主动找外教聊天"
→ "1年级开始上，现在KET说过就是这么快"
```
