## 一、市场调研核心发现

### 小红书：少儿英语爆款规律

**数据基础**：2025年1-7月 1075篇少儿英语笔记分析，取Top50爆款研究

**三大爆款内容方向：**

| 类型 | 关键词 | 爆点逻辑 |
|------|--------|---------|
| 备考冲刺 | KET/PET/口语无痛/短期提分 | 焦虑 + 即时解决方案 |
| 亲子互动 | 游戏化学习/动画跟读/亲子英语 | 温暖感 + 可复制 |
| 对比选课 | 报班vs自学/性价比/踩坑经验 | 决策辅助 + 真实感 |

**核心结论：**
- 素人妈妈号 > 品牌号（信任感）
- 家长需求从"看课程"转向"解决我的痛点"
- 标题公式：20字内，制造认知冲突
- 文案模型：SCQA（背景→冲突→问题→答案）

---

### 抖音：K12英语爆款规律

**基于学而思/新东方106个账号分析**

**爆款视频类型排行：**
1. 🥇 **语言教育类**：动漫/影视剪辑+英汉对比字幕 — 制作成本低，播放量最高
2. 🥈 **家庭教育口播**：家长号、单人口播，粉丝垂直，转化率高
3. 🥉 **真实课堂场景**：外教上课实录，场景错位带来代入感
4. **情景剧**：效果最强，但制作成本高

**账号矩阵经验（学而思）：**
- 一超多强：把流量集中在1-2个主号
- 84个账号，96%粉丝在总部主号
- 其他账号做垂直细分（英语、语文、数学分开）

**获客链路（经验证有效）：**
```
发布内容 → 吸引粉丝关注 → 免费试听/低价引流课 → 表单留资 → 客服跟进 → 付费
```

## 二、竞品内容策略分析

| 品牌 | 主要内容方向 | 优势 | 我们的机会 |
|------|------------|------|-----------|
| VIPKid | 品牌大号+外教展示 | 品牌知名度高 | 已关闭，用户在找替代 |
| 51Talk | 菲律宾外教性价比 | 价格低 | 强调"欧美外教口音更纯正" |
| 阿卡索 | 外教互动视频 | 内容量大 | 强调"固定外教不换人" |
| 贝达 | 成人英语为主 | 成人市场 | 我们专注青少年，更专业 |

**竞品用户痛点（可以抢）：**
- VIPKid用户已无处可去 → 主动接盘
- 51Talk用户嫌菲律宾口音 → "欧美外教"是我们差异点
- 阿卡索用户嫌老换外教 → "固定外教"是我们差异点

## 三、YiYi英语内容策略定位

### 获客阶段 vs 销售阶段（你的价格海报是销售阶段的）

```
[获客阶段] ← 我们现在要做的
兴趣激发 → 信任建立 → 预约试听

[销售阶段] ← 顾问来做
试听体验 → 价格对比（价格海报）→ 付费
```

### 我们的差异化钩子（所有内容都要围绕这3点）

1. **固定欧美外教**（vs 随机换外教、vs 菲律宾口音）
2. **专注3-15岁**（vs 成人课程缩水版）
3. **教学管家全程陪伴**（vs 交钱不管）

## 五、内容执行优先级

**第一批先做（最容易出效果）：**
1. 妈妈号："我花了2万给孩子换了4家英语机构，最后选了这家"
2. 妈妈号：孩子3个月前后英语对比
3. 老师号："选外教英语课必问的4个问题"
4. 萌娃号：孩子跟外教的真实互动视频
5. 品牌号：外教介绍系列

**不要先做：**
- 价格海报（这是销售工具，不是获客工具）
- 直接推课程链接
- 品牌广告风格内容
