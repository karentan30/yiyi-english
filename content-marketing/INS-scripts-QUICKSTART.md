## 🎬 通用拍摄规格

```
视频比例：9:16 竖版（Instagram Reels标准）
分辨率：1080×1920 px （导出时）
帧率：30fps
编码：H.264 (AVC)
码率：8 Mbps
音频：AAC 128kbps 48kHz

设备：
  ├─ 主摄像头：手机 OR 微单（720p+ 以上）
  ├─ 收音：有线领夹麦（重要！）
  ├─ 灯光：LED补光板 OR 自然侧光
  └─ 三脚架或稳定器（保证稳定）

环境音量：<40分贝（关空调/风扇）
```

## ✍️ 字幕三层体系

### Layer 1：钩子卡（0-3s）
```
字体：48-56px 黑体
颜色：白底黑字 或 半透明黑底白字
位置：全屏居中
动效：缓入 0.5-1s
内容：单独字幕卡，包含数字/冲突/问题
```

### Layer 2：口播字幕（全程）
```
字体：36px 思源黑体/方正粗黑
颜色：白字（根据背景可加黑色描边）
位置：上方30% - 下方20%（安全区）
同步：口播同步显示，2-3字/秒
关键词：加粗/不同色突出
```

### Layer 3：特殊字幕（如需）
```
类型：录音字幕、英文翻译、音效标注
位置：不遮挡主体画面
颜色：与主字幕区分（用灰色或淡色）
用途：补充信息，非重点
```

**字幕工具流程：**
```
剪映自动识别 → 导出SRT → Excel校对 → 重新导入微调 → 导出前屏幕录制验证
```

## 🎵 音乐与音量标准

### BGM 选曲（每集可定制）

| EP | 推荐曲型 | 平台 | 备注 |
|----|---------|------|------|
| 1 | 温暖钢琴 + 专业感 | YouTube Audio Library | "Light Piano Flow" |
| 2 | Lofi/轻弦乐 + 温情 | Epidemic Sound | "Soft Piano" 或 "Warm Flow" |
| 3 | 低沉→升温 | YouTube Audio Library | 开头紧张→结尾释然 |
| 4 | Professional lofi | Epidemic Sound | 权威但不冷漠 |
| 5 | 焦虑→温暖递进 | YouTube Audio Library | 悬念感→释然感 |

### 音量混音标准
```
口播声音：100% (0 dB)
BGM背景音乐：15% (-15dB 相对)
特殊音效（录音/音效音）：-6dB（清晰但不抢戏）
最终标准化：-3 dB LUFS（Instagram标准）

检查方式：用手机扬声器播放，口播清晰可听，BGM陪衬不压低
```

## 📊 剪辑工作流（快速版）

```
Step 1：导入素材 (15分钟)
  □ 主镜头竖版导入
  □ B-roll/插入素材准备妥当
  □ 音乐/音效文件就绪

Step 2：AI字幕识别 (10分钟)
  □ 剪映自动扫全段
  □ 导出SRT文本

Step 3：字幕校对 (30分钟)
  □ Excel逐句核对（不放过1字差）
  □ 重新导入调整时间

Step 4：颜色分级 (20分钟)
  □ 统一应用Warm +8-12
  □ 对比度 +12-15
  □ 饱和度 +3-5

Step 5：音量混音 (15分钟)
  □ 口播：100%
  □ BGM：-15dB
  □ 标准化至 -3dB LUFS

Step 6：关键词高亮 (20分钟)
  □ 字幕加色彩/下划线/加粗
  □ CTA段落强调

Step 7：导出检查 (10分钟)
  □ 1080×1920 px
  □ 30fps
  □ <200MB
  □ 无卡顿/掉帧

总耗时：120 分钟 / 集
```

| **CTA清晰** | 5/5 | 1个单一行动，无歧义？ |
| **品牌调性** | 5/5 | 符合YiYi专业+温暖风格？ |

## 📱 INS 上传配置

### 发布最佳时间
```
首选：周三 / 周四
时间：下午 3-6 PM UTC (根据地区调整)
     = 北美：周三下午 7-10 PM PT
     = 亚洲：周三晚 7-10 PM SGT
```

### 文案公式
```
第1行（钩子）：数字 + 冲突 + 感叹
  例："3个月，从开口就卡壳到流利5分钟"

中段（故事）：问题→过程→结果 (60%)
  例："孩子学了一年还在卡壳..."
  
CTA段（行动）：明确单一行动 (20%)
  例："评论区打'升初中'，我分享规划表"
  
标签（5-8个）：破圈+粘性+互动各2-3个
  破圈：#口音 #VIPKid缩课 #升初中英语
  粘性：#少儿英语 #外教一对一 #英语启蒙
  互动：#你家孩子呢 #评论区见
```

### 贴纸策略
```
问卷贴纸（必用）：
  "你家孩子几岁？" OR "你经历过这个吗？"
  → 增加互动率 30%+

投票贴纸（可选）：
  "菲教 vs 欧美外教?" (EP1)
  "有同样困扰吗?" (其他)
  
倒计时/提醒贴纸（仅限限时内容）
```

## 🔴 常见失误与修复

| 失误 | 症状 | 修复 | 耗时 |
|------|------|------|------|
| 字幕同步差 | 字幕滞后/领先1-2秒 | 重新导入，逐帧调整 | 30分钟 |
| 音量不均 | 某段口播被BGM压低 | Lufs meter重新混音 | 15分钟 |
| 钩子不够吸引 | 3秒停留率<25% | 更换数字/冲突点，重新拍S1 | 2-3小时 |
| 色彩过冷 | 显得不够温暖 | 色温 +8-12，重新导出 | 15分钟 |
| 表演生硬 | 看起来像广告 | 让角色多停顿，取用多个Take选最自然 | 1-2小时 |
| 文件过大 | >200MB无法上传INS | 降低码率至6Mbps或重新压缩 | 10分钟 |
