# YiYi 私域 30天分层每日内容日历（0829）

> **用途**：家长测完英语测评进群后，群主每天在群里发一条适合孩子水平的内容。家长带娃照着行动指令做 = 每日打开 = 留存飞轮。
> **三个群分层**（对应测评段位）：启蒙群 / 进阶群 / 备考群。
> **每周节奏循环**：周一磨耳朵 · 周二拼读或语法 · 周三绘本或阅读 · 周四片单动画 · 周五口语开口 · 周六亲子任务 · 周日复盘。第4周略作收束（成果展示+习惯固化）。
> **每周末插一个 YiYi 软钩子**（周六亲子任务里自然带出），不硬广、无微信号、无提分承诺。

---

## 使用说明（给群主）

- **每天只发一条**。文案 = 内容类型 + 来源 + 一句话行动指令。行动指令是核心，家长照着做。
- **「来源」列标注的是真实公开账号/资源名或知名公开资源**（BBC Learning English / PBS Kids / Super Simple Songs 等）。凡带「团队补当日具体链接」= 发之前运营当天去平台搜到该账号的对应内容，把可点链接补进去。**不要编造 URL，不要搬运付费内容。**
- **软钩子克制**：只在标注 🪝 的日子出现，且以「邀请分享 / 一起来」口吻，不发微信号、不承诺提分。
- **红线**：推荐真实公开资源；名著童话公共领域可用；不承诺效果；未成年监护人语境（对家长说话）；AI 生成内容标 AIGC。
