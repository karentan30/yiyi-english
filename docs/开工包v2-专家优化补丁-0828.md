# 开工包 v2 · 双专家优化补丁（2026-08-28）

> 基于两位顶尖专家（小红书起号操盘手 6.5/10 + 教育增长/私域/合规操盘手 7/10）独立评审。
> 本补丁**覆盖 v1 的对应结论**，未提及部分沿用《精品号矩阵开工包 v1》。
> **两专家共识（最重要）：别急着开14号。先用4个号跑通"内容→进群→测评→报课→续费"整条闭环，跑通再铺。闭环不通，号开越多亏越快。**

## 🔴 P0 护栏（开号前必设，不设=量起来就亏/被罚）

### P0-1 免费外教测评 = 成本黑洞，必须分两层 + 防薅
真外教1对1测评单个真实成本 ¥60-100（外教产能+人力）。量起来每天几十场烧在没付费的人身上，1V1一单毛利才¥40，**结构性亏损，越跑量越亏**。设死：
1. **两层测评**：
   - **第一层（挡薅羊毛·零成本·批量留资）**：AI教材陪练/中教做"娃开口录音→出测评报告(水平+问题+建议)"。绝大多数家长只想知道"娃什么水平"，AI/中教就能给。
   - **第二层（真外教1对1·稀缺）**：只给**筛选过的意向家长**（填详细问卷+明确预算/时间）。真外教测评=半节试听，直接导报课。
2. **防薅硬门槛**：一娃一号一微信只领1次真外教测评（归因去重）；**收¥9.9诚意金**（到课抵扣/报课全退）——砍掉一半羊毛党和放鸽子，不违规（占位费非卖课）。
3. **履约排班**：真外教测评固定时段批量排（如每天20:00-21:00两外教连轴），别散点占产能。
4. 测评报告口径：客观描述+方法建议+"外教课可帮开口"软落点。**不承诺提分、不制造"必须报课"焦虑**。

### P0-2 经营层合规（比文案红线重一个量级，能被罚被关）
1. **预收费不跨期**：单次收费 **≤3个月 / 60课时**（双减明确监管线）；收款主体/合同/发票合规。别用"包过KET/PET""保过班"。
2. **未成年人信息（PIPL）**：采集娃录音/视频/年龄=处理未成年人个人信息，测评留资表单**必须有"监护人同意采集"勾选**；真娃上镜必须书面授权。
3. **宣传=履约（防虚假宣传）**：⚠️ 你产品是"1V1菲教 + 小班欧美"，**别宣传"欧美外教"却让用户约到测评发现是菲教**=虚假宣传+投诉重灾区。宣传口径和实际师资严格一致。

## 一、战略定调改：14号"全做精" → "3-4精品 + 10铺量"分层
v1 的"14个号都做精"被两专家判定**在人力和平台规则上双重不成立**（同源母题+统一钩子=判矩阵限流；真人运营摊薄到全废）。改为：
- **精品号 3-4 个（真人重投）**：①宝妈真人IP（真学管出镜/真娃/真生活流，垂直"哑巴英语→敢开口"单一主题）②独立测评号（中立）③真外教出镜号 ④官方号。真外教/真娃素材、真人秒回全部倾斜给这几个。
- **铺量号 ≤10 个**：只做涨粉款+SEO关键词占位，低强度运营，**明确不追求做精**，就是撒网摇号。用AI/数字人讲中文干货占坑。
- **节奏门**：**第一个月只开2个号**（1宝妈真人+1测评号）跑闭环 → 跑出3套可复制资产（过10%点击率的封面模板/能拿私信的软钩子话术/进流量池的爆款结构）→ 复制到8号 → 稳了到14。**跑通前禁止铺号。**

## 二、起号冷启动 SOP（v1 完全缺失·最致命缺口）
新号前10篇几乎没流量，不养号直接发广告=喂死。每个新号：
1. **养号期（前3-5天）**：模拟真人——正常刷/赞/搜"少儿英语"/关注同类号，**不发任何带钩子/机构感内容**。
2. **破0篇设计**：第1篇必须**纯价值或纯情绪爆点、零钩子零机构感**（先让平台判定"正常优质用户"）。
3. **发布频率**：新号**一天最多1条**（多条=作弊信号）。
4. **限流自检法**：发布后搜自己标题看在不在结果里；用无痕/别的号看笔记是否**只有"关注页"有曝光**（=被限流信号）；连续3篇曝光<500=号可能废。
5. **救号**：疑似限流就**停发所有导流内容，连发几条纯干货养7-14天**再恢复。

## 三、承接链路 SOP（v1 只有"软引导"三字·全链最脆）
逐段堵漏：
- **笔记→进群（替代"私信我"）**：正文/评论区引导**"评论区扣1/扣娃年龄，我私信你"**（公开+动作轻，比"私信我"转化高3-5倍）；**笔记直接挂小红书群二维码**（群二维码平台不封，比外链安全）。**小红书群=缓冲蓄水池**。
- **群/私信→企微（30-50%流失段）**：**别硬导微信**。先把"测评"这个价值动作**尽量留在小红书生态内完成**（群里约测评/小红书视频通话初测），微信做"测评后长期关系"的后置动作。
- **软引导话术**：公开区不留号；**私信一对一可软引导加微信**（"回复【测评】给你安排"、暗号、分批放号、"vx同小红书号"），不群发不诱导。
- **约到率**：测评限时限量稀缺化（"本周仅剩3个名额"）+ 预约锁定+48h/2h两次提醒+空降补位。

## 四、封面策略重做（封面=生死线，v1 最草率）
- 分两套：**涨粉封面=情绪大字报/数字冲击/强对比**（别再绿底思维导图，已烂大街）；**转化封面=真人脸/真娃before-after/真外教出镜**（人脸封面点击率天然高）。
- **CTR考核+A/B**：同选题先出2版封面发不同号，48h看点击率，**<8%的版式淘汰**。封面是唯一值得反复打磨的东西。

## 五、评论区运营 SOP（最高ROI却被 v1 一行带过·配专职人）
1. 每条笔记**自评置顶埋钩子**（钩子放评论，不放正文，让正文干净得像不导流）。
2. **小号专职做评论**：自己爆款下带节奏问"哪家好/求测评"；**去竞品避雷帖/差评帖真实口吻截流**（全案ROI最高动作，配1人专职蹲）。
3. **评论问题→下周选题**回收流程。
4. 私信/评论**30分钟内必回**写进考核。

## 六、1V1→小班升级 + 续费（最赚钱环节，v1 只有战略没话术）
### 价格锚点（决定小班好不好卖）
- 别拿小班¥200 比自家菲教1V1 ¥80-120（显贵）。**锚点用"欧美外教1V1市场价¥300-500"**："欧美1V1要¥400+，我们5人小班同样欧美外教，每人只¥200，还多同伴互动和上台机会"=半价上欧美外教。
- 产品分层：**菲教1V1=日常高频陪练/入门体验；欧美小班=进阶开口实战**。两个产品两种价值，不是"同一课涨价"。

### 升级话术（测评/1V1后临门一脚）
1. 测评后先给**诊断+个性化路线**，把小班包装成"解决方案"不是"更贵选项"。
2. **拼班机制反向逼单**（全案ROI最高杠杆·升级成主线）：小红书发"求组队"笔记攒家长→进同一意向池→凑够5人开欧美小班→"已有3娃还差2个开班，占位吗？"。**一个动作串起获客+升级+满班率**，单独立项放大。
3. 菲教1V1上到一定次数，学管介入"娃进步到能上小班实战了"——升级=进步奖励。

### 续费（7学管真KPI·产品化成固定动作）
- **月度成长记录**（AI陪练前后对比录音+复述视频+外教评语，每月自动给家长）=续费第一引擎，也是AI工具最佳落点。
- **期末/考前活动**叠在续费窗口（课时剩1/4时）。
- **同一小班家长绑成小群**（同学关系=续费护城河），不是大杂群。
- **续费预警**：出勤降/AI工具使用归零/长期不回消息=流失预警，学管主动介入。

## 七、数据闭环（v1 缺·没这张表14号=14个黑箱）
每号每周填**四段漏斗归因表**：`曝光 → 进群 → 约到测评 → 测评转报课`，外加封面**点击率、互动率、私信数、加微数**。阈值：点击率<8%=封面废；互动率<3%=内容废；连续3篇曝光<500=疑似限流。数字驱动加量/砍号，不靠感觉。

## 八、合规松绑（v1 过度保守，白白损耗）
- "绝不留微信号"→改为**"公开区不裸露微信号，私信一对一可软引导加微信"**（走暗号，不群发不诱导）。否则漏斗白损耗。
- 中立测评号"绝不点名拉踩"→改为**"基于公开事实的客观横向对比可点名，不捏造不贬损"**。完全不点名=没测评价值=没人信。

## 九、内容优化（选题层）
- AI外教对冲：别写"AI能否替代外教"的理性辩论（小红书不爆）。改成**"我娃跟AI练了半年，见真人还是不敢开口"带具体娃、带挫败情绪的真实故事**。
- 爆款结构补：标题公式之外，每条要有**3秒钩子（第一句不让人划走）+ 留存钩子 + 结尾互动诱导 + 收藏点**。
- 对标库补"可复制信号"：收藏/赞比、评论区高频问题、发布时账号粉丝量、爆点钩子拆解。**先把"AI口语搭子1.1万"和"6首歌6000词9028"两条逐帧拆透**（比补20条点赞数有用10倍）。
