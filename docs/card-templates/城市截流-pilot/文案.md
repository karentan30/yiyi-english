# 城市截流 · Pilot 文案（本地化截流层）

> 逻辑一句话：家长报班前会搜「城市+少儿英语/外教/幼升小」，这类词竞争最低、意图最高。同一套普适干货用 `{城市}` 变量批量铺，每条截住该城市的本地搜索流量。**城市只是搜索标签，内容是放之四海皆真的普适干货，不编造任何城市特有事实。**

起步城市（6个高客单密度）：北京、上海、广州、深圳、杭州、成都。

## 选题A · 外教怎么选（转化号命脉 · 清单模板）

**截流逻辑**：截住「{城市}少儿英语外教」「{城市}外教怎么选」这类高购买意图搜索——家长搜这个词时已经在准备掏钱，给他5个避坑标准建立专业信任，把决策权还给家长（不点名黑任何机构）。

- **标题模板**：`{城市}家长必看｜少儿英语外教怎么选，5个避坑标准`
- **3秒钩子正文**：
  > 在{城市}给娃找英语外教，别只看「金发碧眼」。同样的价钱，选错老师=白烧一年。这5条是我踩过坑总结的判断标准，收藏对照着挑，不踩雷。
- **评论区引导进群钩子**（图上无微信号，引导走评论）：
  > 整理了一份《外教资质自查清单》，想要的家长评论区扣【外教】，看到就发你。
- **标签**：`#{城市}少儿英语 #{城市}外教 #少儿英语启蒙 #英语外教怎么选 #少儿英语避坑 #英语启蒙 #亲子英语`
- **首图版式**（清单模板 · 暖橙浅色）：
  - 情绪大字：`{城市}家长选外教`
  - 副标：`5个避坑标准 · 对照着挑不踩雷`
  - 配色：奶油浅底 + 橙红标题 + 黄色高亮块（与选题B冷调区分）
  - 底部CTA条：`完整自查清单 · 评论区扣【外教】`
- **5条避坑标准（内页要点 · 全普适不点名）**：
  1. **看资质不看颜值** — 认准 TEFL/TESOL/CELTA 国际教学证，母语国籍≠会教孩子。
  2. **固定老师优于随机匹配** — 常换老师=娃刚熟悉又重来，进度和安全感都断。
  3. **看课堂是否开口** — 好课是孩子一直在说，不是老师一直在演；试听重点看开口时长。
  4. **进度可视 + 及时反馈** — 有清晰课后反馈和阶段目标，才知道钱花在哪、进步在哪。
  5. **退费与请假规则写进合同** — 报课前把退费、请假、老师更换规则问清落纸，别信口头承诺。

## 选题B · 幼升小英语要准备到什么程度（季节高搜 · 路线模板）

**截流逻辑**：截住「{城市}幼升小英语」这类季节性高搜词（升学季暴涨）——家长焦虑但没方向，给一条按年龄的「不焦虑参考」路线，全程强调「兴趣＞刷题」，稳住情绪同时建立信任。**不制造入学焦虑，不编造任何城市的入学要求/学校/教材。**

- **标题模板**：`{城市}幼升小英语｜一年级前准备到什么程度（不焦虑参考）`
- **3秒钩子正文**：
  > {城市}的家长别被「别人家娃已经能读章节书」带焦虑。一年级前英语不用超前，按娃的节奏来就行。这份按年龄的参考，帮你心里有底、不盲目鸡娃。
- **评论区引导进群钩子**：
  > 做了一版《幼小衔接英语启蒙节奏表》，需要的评论区扣【衔接】，发你参考。
- **标签**：`#{城市}幼升小 #{城市}少儿英语 #幼小衔接 #英语启蒙 #幼升小英语 #不焦虑育儿 #英语启蒙路线`
- **首图版式**（路线模板 · 冷暖过渡浅色）：
  - 情绪大字：`{城市}幼升小英语`
  - 副标：`一年级前按这4步就够了 · 进度慢点也没关系，学校会从零系统教`（不焦虑心态提醒直接写进副标，首图即安抚）
  - kicker小标签：`不焦虑参考`
  - 配色：暖米底 + 深棕标题 + 各阶段绿/蓝/橙渐进色带（与选题A纯暖橙区分）
  - 底部CTA条：`完整节奏表 · 评论区扣【衔接】`
- **各年龄准备程度（首图4步 · 全普适「够用即可」表述）**：
  1. **3-4岁 · 磨耳朵** — 每天10-15分钟儿歌动画，建立英语好感，不要求开口，听得进去就赢了。
  2. **4-5岁 · 敢开口** — 会说日常问候和简单指令、能跟读，敢开口比说得标准更重要。
  3. **5-6岁 · 见字母** — 认全26字母大小写、熟悉自然拼读起步（字母发音），别急着背单词。
  4. **6岁 · 拼读+分级读物** — 能拼读简单单词、读初级分级绘本，兴趣还在就已经很好了。
  - **心态提醒（写进首图副标 + 正文强调）** — 起点不同很正常，进度慢一点也没关系；一年级学校会从零系统教，别用超前制造焦虑。（路线首图模板固定高度只稳放4步，第5条安抚上提到副标，反而更醒目）

## 发布节奏建议（防重限流 · 务必执行）

同一账号一天连发6城市近似卡 → 平台判定为**批量重复/搬运**，会限流甚至限权重。执行守则：

1. **一号一天最多发1张城市卡**，6城市 = 分散到6天，或分散到多个矩阵号（一诺妈/团团妈/Lucy老师等各领1-2城市）。
2. **错峰发布**：不同城市卡换发布时段（早08:00 / 午13:00 / 晚21:00 轮换），标题措辞也做微调（如「必看」「参考」「避坑」轮换），降低近似度。
3. **优先本地流量号**：若某矩阵号IP/定位在该城市，用它发对应城市卡，本地推荐权重更高。
4. **两选题错开**：同一号别同一天同时发A和B，隔开发以免被判系列灌水。
5. **先跑2城市测数据**（如上海+成都），数据（收藏/评论/进群）验证格式成立，再铺其余城市。

## 城市列表如何扩到更多城市（一句话）

`spec.json` 里城市是纯变量——扩城市 = 复制 A/B 两条卡、把 `{城市}` 全局替换成新城市名（如「南京」「武汉」「苏州」），追加进数组重跑脚本即可，内容一字不改（因为全是普适干货），一个新城市 = 加两行。
