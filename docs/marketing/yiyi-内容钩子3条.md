# YiYi English · 内容钩子 3 条（复用 Lumee 模式开局）

> 模式参照 Lumee：**真人真声护城河 + 对话气泡高转化 + $1/条外教内容+爆款奖金 + 宽场景变体**。
> 钩子必须咬住 YiYi 三个差异化死点：**①固定欧美外教 ②专注 3-15 岁 ③教学管家伴读**（对齐 `01-调研报告.md`，不推价格海报做获客）。
> 拍摄成本都压到最低：一部手机 + 外教真人出镜 / 对话气泡排版，每条约几十元制作成本（外教 $1/条 + 爆款奖金从 Lumee 模板平移）。

## 钩子 1：外教真人出镜 ·「我家孩子第一个说'老师别走'」

**画面**：欧美外教 Ms. Emily（真实出镜，自然放松）对着镜头；右下角配孩子跟读的中英对照耳语气泡。
**台词（外教口播，可配中文字幕）**：
> "家长们不是总问：孩子怎么才愿意开口说英语？今天让我家这位小班告诉你。我跟同一位孩子固定见面第 12 周——从第 1 周只会点头，到这周主动跟我说 'Don't go, teacher!'。固定外教给孩子的，不只是口音，是安全感。因为安全感，孩子才敢开口。"

**钩子点**：固定欧美外教（@死点①）；"孩子主动说老师别走"= 情感引爆 + 可转发的萌点。
**变体**：
- 换孩子跟读片段（同模板不同小孩）
- 换场景：睡前故事、作业错题讲解
- 换 hook 句：`曾经躲着英语的孩子，现在追着老师聊天`

## 钩子 2：对话气泡 ·「3 岁 vs 13 岁，英语启蒙真不是一回事」

**画面**：满屏对话气泡，左边外教短句 EN，右边孩子中文（或拼音），三种不同年龄段并排对比。节奏参考 Lumee 对话气泡"左右交替 + 明显留白 + 高亮关键句"。
**文案逻辑（SCQA）**：
- **情境**：3 岁靠磨耳朵，13 岁要靠体系。
- **冲突**：很多家长用一套方法硬套全年龄，孩子要么听不懂挫败，要么觉得幼稚。
- **问题**：怎么不同年龄都教对、教得明白？
- **答案**：YiYi 专注 3-15 岁，按 CEFR 分级 + 固定外教按孩子年龄/水平定制——每个年龄有它该上的那节课（@死点②）。

**钩子点**：知识冲突（年龄 ≠ 一套教法）制造认知反差，极易转发；排版成本极低（纯气泡可做成静态图/短视频）。
**变体**：
- 换成"雅思妈妈选课 vs 佛系妈妈选课"对比
- 换成"菲律宾口音 vs 欧美口音"对话对照（@死点①，接盘 51Talk/VIPKid 用户）

## 钩子 3：短剧/连麦式 ·「报了课，孩子却没上几节——问题不在孩子」

**画面**：家长第一人称手机自拍，语气无奈又好笑；可切 1-2 格"管家排课"的对话气泡。
**台词**：
> "报了英语班，结果一个学期老师换了仨，孩子每节课都在认识新面孔、重新认生。后来我懂了一件事：孩子英语进度慢，很多时候不是孩子的问题，是'关系'没建立起来。我们现在固定同一个外教，还有一个教学管家帮我盯每周的课、课后反馈、调整节奏——我不懂英语教育，但有人真的在管（@死点③）。"

**钩子点**：把"报了课却没效果"这个最大顾虑摊开讲，用"换老师/没人管"痛点反衬 YiYi 的"固定外教 + 教学管家"差异化，转化路径最直接（共鸣→私信试听）。
**变体**：
- 换"孩子 3 个月前后开口对比"实证
- 换"妈妈看到外教每月一份学习反馈"的爽点特写
