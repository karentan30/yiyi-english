# 小孩游戏化机制调研（0829）
## 给「20座岛冒险地图 + 段位称号」少儿英语测评成绩单的设计依据

> 目标：给孩子（6-14岁·男女）测完英语出「英语冒险地图」，20座岛=水平进度，每座岛要有孩子爱炫耀、家长爱截图的称号。以下全部抄经过市场验证的真实案例，不瞎编。

---

## 核心结论（先看这三句）

1. **孩子最吃的机制**：不是单一段位名，而是「天生就懂的价值阶梯（金属/宝石/生物/神话）」+ 情绪修饰词（倔强/永恒/至尊）+ 五件套（变量奖励·集齐完形·稀有炫耀·进度可视·赛季重置）。留存证据最硬的是 **Streak 连续打卡（10天是留存生死线）** 和 **30人小组周赛段位联赛**（Duolingo 上线排行榜后学习时长+17%、高活用户翻3倍）。
2. **男女通吃的关键**：走「探索 + 收集 + 成长」这条轴（是唯一被研究点名跨性别通吃的机制）；**避开纯打斗武力值**（女孩无感）和**纯粉色公主换装**（男孩无感）。用中性小探险家角色（动物/机器人/小宇航员，别做明确男女主角）。
3. **家长最爱晒的卡**：**「打卡天数/坚持类」转发率最高**（晒的是努力这一美德，炫耀羞耻最低）；「分级段位晋级」做骨架（借权威背书）；「超过XX%同龄人」只做角落点睛（最能炫但招黑，别当主标题）。

## ① 游戏段位规律 + 可抄点

### 六大游戏的真实段位/称号/稀有度

**王者荣耀**（"情绪修饰词+物质意象"双词命名典范）
倔强青铜 → 秩序白银 → 荣耀黄金 → 尊贵铂金 → 永恒钻石 → 至尊星耀 → 最强王者（王者→至圣王者→无双王者→非凡王者，用星级无限细分）。
- 骨架=金属/宝石天然价值序列（青铜<白银<黄金<铂金<钻石），孩子零门槛就懂；修饰词负责注入情绪身份。顶段用星级制造"永远差几颗星"。

**蛋仔派对**（萌系"蛋"隐喻，低龄化）
一阶鹌鹑蛋 → 鸽子蛋 → 鸡蛋 → 鹅蛋 → 鸵鸟蛋 → 恐龙蛋 → 巅峰凤凰蛋。
- 从"最普通的鹌鹑蛋"到"神话凤凰蛋"，一条"平凡→神话"成长叙事，比金属体系更适配低龄。**新手段位不掉星**（防挫败流失）。

**迷你世界**（弱段位+多榜单收集，社交型）
段位蹭王者荣耀（青铜→王者）；核心是全服榜/好友榜/赛季榜/周榜，只上榜前100名（稀缺展示位）；赛季/周定期重置。

**宝可梦**（双层稀有度）
- 闪光（异色）：概率1/4096~1/8192，纯稀有度炫耀，单独解锁闪光图鉴。
- 卡牌罕贵度：C < U < R < RR < SR < UR/HR < SSR/SAR，一盒常仅1张SR。
- 双钩子="图鉴集齐（完形）"+"稀有个体（闪光/UR）"，孩子"全都要"。

**我的世界**（无段位，靠"进度"收集）
125项进度分5大类，任意模式可完成，本质=成就图鉴，靠"点亮全部"完形收集。证明**非竞技产品可只靠清单式收集**形成长期目标——最贴近"20岛点亮"。

**原神**（星级+命座重复收集）
4星/5星，限定5星0.6%、90抽保底；命座0命→满命6层（重复获得转深度收集）。满命=终极炫耀符号。

### 上瘾机制清单（9条）
① 变量奖励（下一发可能出金）② 收集完形（集齐一套）③ 稀有度炫耀（社交货币）④ 进度可视化（段位条/星级/百分比）⑤ 段位=身份圈层 ⑥ 赛季重置（防到顶流失）⑦ 防挫败护栏（新手不掉星）⑧ 资源稀缺原则（泛滥即失效）⑨ 顶端无限细分（最强也永远差一点）。

### 可抄的命名法则 + 修饰词库
**双词结构**：情绪修饰词 + 天然价值意象（金属/宝石/生物/神话）。底层给共鸣，顶层给封神。
- 底层（自嘲励志不劝退）：倔强、初心、微光、萌新、青涩
- 中层（进阶体面）：秩序、荣耀、尊贵、闪耀、精英
- 高层（贵气稀有）：永恒、至尊、璀璨、传世、无双、非凡
- 封顶（封神加冕）：最强、巅峰、至圣、传说、王者、神话、超凡

## ② 教育App奖励机制 + 可抄点

### 各App机制清单
**Duolingo**（标杆，机制最全）
- Streak连续打卡（3→7→14→30→…→365天逐级点亮）
- League联赛10段：Bronze→Silver→Gold→Sapphire→Ruby→Emerald→Amethyst→Pearl→Obsidian→**Diamond**。每周30人一组，前几名晋级/末尾降级，段位越高奖励越多。
- XP经验值、Gems宝石（买护级道具）、Achievements徽章
- **Streak Freeze护级**（损失厌恶核心，花宝石买"漏一天不断连"）、Perfect Streak完美连胜、7天进Streak Society专属俱乐部。

**斑马App**：课程分级S1-S5（对标GRL）；闯关地图；**斑马币→商城兑实体玩具**（国内公认最上瘾一环，孩子为集币反复刷题）；勋章星星；家长学习报告。

**伴鱼**：4000+原版绘本分级（对标RAZ）；徽章/星星/帽子/奖杯收集；**成长圈=家长社交晒打卡**。

**洪恩**：积分卡/主题卡/稀有卡/贴纸集卡（收集拥有感是核心钩子）；场景化闯关；勋章。

**RAZ**：aa→Z2 字母分级（26+级），挂靠Lexile蓝思框架+美国年级标准。系统给"当前级或略高一档"的书。

### 有留存数据支撑的机制
| 机制 | 证据 |
|---|---|
| 社交排行榜/段位 | 学习时长+17%，高活用户翻3倍，D1/D7显著改善，课程完成率+25% |
| Streak连续打卡 | **达10天streak流失概率大幅下降**（关键拐点）；streak用户约2x日留存 |
| Streak护级/连胜赌注 | Day7留存+14% |
| Streak整体策略 | 留存从12%拉到55% |
| 深度参与排行榜 | 每周多完成40%课程 |

**四大验证机制**：①Streak连打（10天生死线）②社交排行榜/段位 ③损失厌恶护级 ④每日目标。

### RAZ分级命名逻辑 + 家长为什么买账
用字母序列（aa→Z2）刻意与年龄脱钩，柔和不像成绩单。家长认账因为：①有科学框架背书（Lexile+美国标准，"不是App瞎编"）②可迁移通用货币（"我娃读到M级"全行业都懂=社交货币）③精准适配最近发展区（跳一跳够得着）④26+级台阶把"英语进步"变成可数可晒的刻度，接住家长焦虑。
⚠️坑：级别一旦被当"成绩单分数"且与年龄硬绑会制造焦虑——要强调"这是起点坐标，不是评判"。

### 可抄给测评地图
- **A. 字母/命名分级做测评结果骨架**（抄RAZ）：给带命名的级别坐标而非冷分数，挂靠可信框架（CEFR/Lexile/GRL）做背书。
- **B. Streak+10天拐点**（抄Duolingo，数据最硬）：测评后引导每日打卡，首要目标推过10天生死线，配护级道具。
- **C. 段位联赛+每周晋降级**（抄Duolingo League）：30人小组周赛，可做班级/城市/年龄段榜。
- **D. 虚拟币+商城兑换**（抄斑马币，国内最上瘾）。
- **E. 收集型集卡/勋章**（抄洪恩，含稀有卡）。
- **F. 家长报告+晒娃社交**（抄斑马Report/伴鱼成长圈）：双端激励，孩子玩游戏化、家长看进度卡做分发。

## ③ 男女通吃的命名/视觉原则

**研究结论**：性别差异真实，但集中在"竞争打斗 vs 温柔照护"这一条轴；**"探索/收集/成长"是唯一被点名跨性别通吃的最大公约数**。且同龄段内个体差异 > 性别差异——不要过度性别化，风险大于收益。

**✅ 通吃词/主题（安全区）**
| 类别 | 具体词 |
|---|---|
| 探索发现 | 探险家、探索、发现、地图、寻宝、探宝、未知世界 |
| 星球宇宙 | 星球、星际、太空、星图、星球探险家（中性感最强·市场高频） |
| 成长养成 | 成长值、成长星、养成、进化、解锁、点亮 |
| 收集 | 徽章/勋章、集卡、图鉴、收集册、点亮地图 |
| 旅程关卡 | 冒险地图、闯关、旅程、里程碑、通关 |

**⚠️ 踩雷词（让一半孩子无感）**
- 纯打斗武力值：战力、击败、武力值、PK、军团、爆兵（女孩无感+家长对暴力敏感）
- 纯粉色公主向：公主、化妆、换装、过家家、照顾娃娃（男孩无感）

**视觉中性方案**：星空蓝紫 + 探索橙黄的探索色板；圆润几何；**拟人化中性角色（动物/机器人/小外星人/小宇航员，而非明确男女主角）**——学术上正是用非人类/年龄模糊角色规避性别投射。避开满屏粉与迷彩血红（都是单性别信号）。

## ④ 家长爱晒的成就卡类型（按转发率排序）

底层驱动：朋友圈通过"持续在线+跨地域比较"放大攀比；家长晒娃核心情绪是"我家孩子优秀"的自豪感。**能同时满足"自豪+可对比+努力可见"的卡最好晒。**

1. **打卡天数/坚持类（转发率最高）⭐** — 晒的是"坚持/努力"这一美德，炫耀羞耻最低，家长发起来心理负担小。机构用它做裂变（打卡60天得证书全国家长自发晒），Duolingo每天数百万人晒streak。命门=连续天数、累计天数、累计本数/时长。
2. **分级/段位晋级类（权威背书·转发率高）⭐** — 借第三方权威分级，晒的是"客观等级"非自评。"我娃读到Level M"本身就是段位炫耀。命门=级别徽章+"北美X年级水平"锚点。
3. **证书/结营类（仪式感强·中高）** — 看得见的官方认可，但偏"完成"不偏"超越"，炫耀含量略低。
4. **"超过XX%同龄人"对比类（炫耀欲最强但招黑）⭐⚠️** — 稀缺性=炫耀最高燃料，把自豪感直接量化。但双刃剑、显功利、需真实样本。**最佳用法：卡上一行点睛数据，不做整卡主题。**
5. **纯成绩单式（转发率最低）** — 太赤裸功利、招黑、中低分家庭无法晒、覆盖面窄。

**四根炫耀杠杆（可叠加）**：①稀缺性（超90%同龄）②可视化进度（地图点亮/进度条/等级）③权威背书（分级/证书/北美对标）④努力可见（打卡天数——转发率之王，最降炫耀羞耻）。

**晒卡落地要点**：主视觉=中性小探险家点亮世界地图；卡上4类信息按权重=【坚持天数主角大字🔥】+【地图已点亮X/Y岛】+【当前等级≈北美同龄水平】+【超过XX%同龄小探险家·角落点睛】。用Canvas动态合成海报（小程序不能直接分享朋友圈，须生成图引导保存转发），带小程序码回流；在升级/结营/连胜里程碑的情绪高点主动弹可分享卡；加家庭共同streak做双人问责。

## ⑤ 按年龄段的建议

**核心思路：同一套「20岛地图+段位」骨架，随年龄从"可爱收集"平滑过渡到"段位竞技/身份炫耀"，比重此消彼长，不做三套产品。**

| 维度 | 6-8岁 | 9-11岁 | 12-14岁 |
|---|---|---|---|
| 机制比重 | 可爱收集85%/竞技15% | 收集45%/竞技55% | 收集20%/竞技+身份80% |
| 命名风格 | 具象可爱 | 具象+荣誉混合 | 抽象酷炫/头衔化 |
| 岛屿命名 | 泡泡岛、彩虹岛、小海豚湾 | 宝石岛、探险家群岛 | 挑战域、试炼之境 |
| 段位称号 | 小探险家/星星收集家 | 青铜→黄金勇者/稀有徽章 | 语言大师/王者段位/精英级 |
| 视觉 | 高饱和暖色·圆润·动物IP·大量撒花动画 | 宝石质感·稀有度分级发光·徽章墙 | 深色克制·金属质感段位牌·极简酷·可分享成就卡 |
| 奖励物 | 贴纸/星星/盖章/点亮 | 稀有徽章/连击/周榜名次 | 段位牌/头衔/里程碑/身份展示 |

- **6-8岁**：注意力短、要即时正反馈（每完成一小步撒花/贴纸/盖章）；回避排名比较、稀有度、延迟奖励。岛=可爱动物岛，段位只做低调成长可视化不排名。
- **9-11岁**：收集心理学峰值期（"catch them all"+稀有度=价值），开始享受竞争排名和同龄比较。红线=**不能用排名羞辱落后者**，用30人小组周榜让竞争"感觉可赢"，不暴露真实成绩公榜。
- **12-14岁**：核心诉求是身份认同、段位炫耀、"酷"。**强烈回避"幼稚"信号**（原色/夸张动画/过度俏皮UI被本能拒绝）。默认可隐藏在线状态/关闭排名，避免社会比较焦虑。

**渐进式设计原理（自我决定理论SDT）**：任何年龄都要同时满足自主/胜任/关联三需求。把徽章当"胜任反馈+有意义选择+社交连接"而非"控制手段"——后者会侵蚀内在兴趣。
- 一张20岛地图打底，视觉自适应年龄：低龄看到可爱岛屿+撒花，中童看到宝石段位+徽章墙，大童看到酷炫试炼域+可分享成就卡。
- 岛屿进度（具象可点亮）=全年龄通用地基。段位系统一套贯通、称号措辞分龄（同阶梯只换文案视觉）。
- 三条护栏：竞争用小规模周榜；绝不排学习成绩公榜；大童默认可关排名。

## ⑥ 给「20岛英语地图」的3条具体命名/机制建议（有依据）

### 建议1：20岛用「探索意象阶梯 + 情绪修饰词」双词命名，挂靠CEFR/Lexile做家长背书
**依据**：王者荣耀"倔强青铜→荣耀黄金"证明双词结构零学习成本；RAZ证明挂靠权威框架家长才认、才敢晒。
- 骨架走**探索/星球意象**（男女通吃），别用金属打斗味太重，也别用纯萌蛋太低龄——用"岛屿群→大陆→星球"的世界探索升格。
- 每岛=情绪修饰词+探索意象，底层给共鸣、顶层封神。示例阶梯：
  `启航海湾（Lv.1）→ 微光珊瑚岛 → 探索者群岛 → 荣耀灯塔岛 → 璀璨宝石岛 → 星港（第10岛·中点里程碑）→ …→ 无双风暴岛 → 至圣云端岛 → 传说星辰岛（第20岛·封神）`
- 每岛底部小字标注"≈CEFR Pre-A1 / Lexile 200L / 北美K年级"，家长一眼懂含金量。
- **落地要点**：第10岛设"中点里程碑"给大奖+可晒卡（Duolingo证明里程碑情绪高点是分享黄金点）；20岛封神岛用"传说/星辰"这类唯一词=加冕。

### 建议2：地图叠加「Streak连续打卡 + 30人小组周赛段位」双留存引擎，冲10天生死线
**依据**：Duolingo数据最硬——排行榜使学习时长+17%/高活翻3倍/完成率+25%，streak达10天流失概率大幅下降，streak整体策略把留存从12%拉到55%。
- 测完给地图坐标后，**立刻引导每日复测/打卡**，火苗可视化，首要目标是把用户推过10天拐点。配"护级道具/星星保险"接住漏一天的挫败（损失厌恶留存器）。
- 段位联赛做**30人小班周赛**（可按班级/城市/年龄段），前几名晋级末尾降级——但**9-14岁只用小组周榜、绝不排真实成绩公榜**（保护后进生自尊），大童默认可关排名。
