# 群运营 SOP（2026-08-28）

> 群=承接池。所有号引流到1-2个总群，群里转化。定位：有温度的家长福利/答疑群，不是卖课群。

## 一、进群（承接）
- 引流：评论区+主页群二维码（不靠私信，私信多易封）
- 自动欢迎语：
  > 欢迎进群🌸 这里是XX家长交流群。进群先领：①分级书单 ②磨耳朵歌单 ③启蒙路线图（群公告/置顶）。每天分享一个实用点，也可随时问娃的英语问题~
  > （采集娃录音/信息做测评前，会先征得您作为监护人同意）

## 二、日常节奏（促活·别冷群）
- **每天**：1个干货点 / 1句地道表达 / 1个真实案例片段
- **每周**：晒真实学员成果（授权）+ 集中答疑 + 限时免费测评名额
- **互动机制**：家长打卡（娃今天学了啥）、话题讨论、答疑接龙
- 群冷了：抛一个家长都关心的问题（选校/教材/开口）引讨论

## 三、转化（群→报课）
```
进群领资料 → 群内建信任(干货+案例+答疑) → 约免费测评
→ 群内1对1发联系方式/加微 → 测评报告 → 试听 → 报课
```
- 🔴 **发微信只在1对1场景**（不群发、不刷屏，平台对群内导流也监测）
- 测评：先AI/中教初测（防薅），意向强再真外教1对1
- 别硬广：群里90%是价值，成交是副产品

## 四、分工 + KPI
- **群主=学管**：欢迎/答疑/30分钟必回/约测评
- **KPI**：进群数、群活跃、测评预约、报课、续费（不只看群人数）
- **裂变**：老带新——邀请同龄娃家长，双方各得资料/试听

## 五、红线
- 监护人同意采集未成年信息
- 不群发导流、不硬广、不承诺提分
- 分销只一级
