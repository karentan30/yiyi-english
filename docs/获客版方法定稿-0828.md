# 获客版 · 内容方法定稿（2026-08-28）

> 经专家评审修正：从"追收藏"改成"追私信/进群"。收藏是虚荣，私信才是命。
> 本文覆盖之前的LOOP，是最终执行标准。

## 一、核心修正（专家审 + Karen实战）
1. **收藏≠获客**：平台弱化纯收藏、抬互动率。纯干货图集是"收藏黑洞"。**数据看私信/进群/测评数，不看收藏数。**
2. **真人素材是命门**：母婴靠信任，AI批量产一眼假。真外教/真娃/真宝妈素材=护城河。**AI只在真素材上放大，禁凭空编育儿经历。**
3. **专家审≠裁判**：审只管合规+基础质量；内容好不好交**数据A/B**判。
4. **8号别一套公式**：按漏斗位分KPI（下）。
5. **防限流**：8号封面版式/发布时段/设备IP差异化。

## 二、转化位（每帖必带·评论进群，不靠私信）
```
笔记(评论区置顶钩子) → 主页群入口/评论引导 → 进小红书群 → 群内1对1发联系方式 → 测评 → 报课
```
- 🔴 **私信最小化**：私信导流多=封号。**只被动回主动私信来的人，绝不主动群发私信。**
- **主要靠评论区 + 主页**引导进群（群二维码挂主页，评论区置顶"进群方式看主页"）
- **进群后**在群内发联系方式（群是私域，比笔记留微信安全）
- **测评页**可直接收联系方式（价值交换，合规）：`测评H5 → 家长留微信/手机 → 学管1对1发报告`
- 图上/正文**永远无微信号**

## 三、8号漏斗KPI（别一套指标考所有号）
| 号类型 | 号 | 内容 | KPI | 素材 |
|---|---|---|---|---|
| **引流号** | 书单/动画/榜单/一诺妈启蒙 | 高收藏图集/榜单 | 收藏率+主页访问 | 可纯AI量产 |
| **信任号** | 团团妈/外教Ryan | 真实故事/真外教出镜 | 关注+进群+私信 | 🔴**必须真人素材** |
| **权威号** | Lucy教研 | 方法论/教材解读 | 收藏+进群 | AI+专业把控 |
| **转化号** | 号2避坑/校内配外教 | 测评/对比/避坑 | **进群+测评预约** | AI+真实案例 |

## 四、真实素材库（LOOP强制上游·每周采）
- 真外教：课堂片段/纠音示范/教一个表达（每周2-3条真人真声）
- 真娃：开口前后对比/作品/演讲（家长授权）
- 真宝妈：真实反馈/真实提问/踩坑经历
- **AI用真素材放大成8-15张图/视频，不无中生有**

## 五、视频（流量号·旁白讲解）
- **图文卡 + 旁白讲解 + 字幕滚动 = 视频**（剪映免费，卡片一图两用）
- 旁白：干货类AI配音/真人；英文示范用真外教音
- 视频号流量比图文大，引流号可主做视频

## 六、修正后LOOP
```
① 跨品类抓爆款(不只本赛道) + 注入外部信号(私域真实提问/竞品新爆款)
② 关键词×母题选题
③ 真实素材库(上游) + AI放大 → 派agent写文案
④ 高密度内页(8-15张/榜单密卡) + 转化位(评论进群)
⑤ 合规检查(不是"审到10分当裁判")
⑥ 发布 → 看私信/进群数(不看收藏) → A/B → 转化高的加量
⑦ 回①(带新外部信号，防近亲繁殖)
```
