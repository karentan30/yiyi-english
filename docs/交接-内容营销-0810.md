## 三、内容策略定位

**目标用户：** 25-40岁，有6-14岁孩子的妈妈

**核心差异化：** 固定同一个外教（vs 竞品换来换去）

**内容三类型：**
1. 家长焦虑共鸣（孩子哑巴英语、考高分不敢开口）
2. 干货方法（怎么选外教、怎么练口语）
3. 真实案例（学员进步故事）

**转化路径：**
```
小红书图文/视频 → 评论引导私信 → 主页链接 → lp-free-trial.html → 填手机注册 → 微信跟进
```
