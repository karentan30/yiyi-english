## 二、钩子形态轮盘（防同质·防限流核心）

每号每周内，钩子形态**不连续同质**，按下轮盘轮着来：

`损失 → 自曝 → 冲突 → 数字 → 纠错 → （回损失）`

- **损失**：选错歌白磨了/一上台就哑火/信心被打没
- **自曝**：我家娃考95分却开不了口/我当年也踩过这坑
- **冲突**：名校 vs 普通校/线下 vs 线上/菲教 vs 欧美
- **数字**：KET 120→140 价值翻倍/5本不如1本/9泛1精
- **纠错**：第一步别背26字母/顺序反了全白费/贵≠适合

> 规则：**同一号相邻两条不用同一钩子形态**；每周4号横向看，同一天四号尽量四种不同钩子。

## 五、A/B 与放量规则

1. **同母题出 2 版钩子**：每个上新选题准备 A/B 两版（如"损失"版 vs "数字"版），同号错开 1–2 天发。
2. **测**：以 **72h 进群数 / 测评数** 为准（不以收藏），高者为赢家。
3. **加量**：赢家钩子 → 下一周排入"加量位"重做同选题；并把该钩子形态优先复用到同号其他选题。
4. **止损**：**同一母题连续 2 条进群数沉底**（低于该号中位数一半）→ 停发该母题，换池中未用母题（储备 107 条足够轮换）。
5. **信任号特权**：信任号即使收藏低，只要**进群/私信质量高**就继续投——它是转化命门，不与引流号比收藏。
6. **防近亲繁殖**：每周回抓 1 个跨品类外部爆款信号注入选题（对齐定稿 LOOP ⑦），避免钩子内卷同质。
