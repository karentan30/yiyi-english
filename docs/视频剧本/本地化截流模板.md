# 本地化截流 · 6条通用模板（团队按本地填占位）

> 用途：蹭本地学校/机构/城市搜索词，截流"报班前会搜小红书对比"的本地家长。
> 用法：把【城市】【学校名】【机构名】等占位替换成本地真实名字即可发。
> 时长约30秒｜背景走免费视频库(Pexels/Pixabay/Mixkit/Coverr/Videvo)｜配音+字幕剪映拼。
> 🔴红线：学校信息型=只客观盘点不承诺录取、不虚假背书；机构对比=中立基于公开事实、不点名黑不拉踩(诽谤)；一律不承诺效果；图/正文/评论无微信号，转化=评论进群。
> ⚠️ 别用可辨识真实孩子/校门牌匾特写(肖像权+侵权风险)，用免费库通用镜头+文字卡呈现校名/机构名。

## 通用制作说明

**免费背景视频库**：Pexels Videos / Pixabay Videos / Mixkit / Coverr / Videvo（免费商用）。搜上表英文词即有。
**制作流程**：免费库下背景 → 剪映配音（亲切语气）→ 大字字幕压屏 → 校名/机构名用文字卡呈现，不放实拍。
**发布策略**：标题+话题带本地词（#【城市】少儿英语 #【学校名】 #【城市】幼升小 等），蹭本地家长搜索。

## 🔴 合规红线（每条发布前自查）
1. 学校信息型：只客观盘点，**不承诺录取、不说"内部名额/保过/包上"、不虚假背书学校**。
