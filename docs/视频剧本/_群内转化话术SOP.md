# 群内转化话术 SOP（进群→测评→报课）

> **这是最赚钱的一环，之前是空的。** 笔记只做到"评论进群"，人进了群怎么1对1聊成，全靠这份逐句话术。
> 上游承接结构见 `私域承接落点SOP-0828.md`（五落点）、`群运营SOP-0828.md`（群定位/节奏）、`wechat-community-sop.md`（社群运营/朋友圈）。本文**不推翻，只补齐最缺的那段：群里逐句怎么说。**
>
> 🔴 **合规铁律（每一句都不能破）**
> - 不承诺提分/包过/多久见效。只说"更敢开口 / 帮娃定位卡在哪 / 补上缺的那一环"。
> - 联系方式**只在群内1对1场景给**，笔记/评论/公开图上永远无微信号。发的是**口令/群二维码**，不是vx。
> - 不制造虚假紧缺（不说"最后1个名额"如果不是真的）。名额、时段限制必须是真实存在的。
> - 未成年信息**按需最小收集**，采集娃录音前必先拿到监护人明确同意。
> - 师资诚实：说是中教初测就是中教，说真外教就是真外教，不诱饵调包。
>
> **心法**：你是懂行的学管老师，不是销售。90%给价值，成交是副产品。多问少推，先帮她把娃的问题看清楚，方案自然就成立了。

## 模块1 · 进群欢迎语（自动/置顶·价值交换感·引导先测评不硬推）

> 家长刚进群第一眼看到的。目标：让她觉得"进对了群"，并埋下"先给娃测一下"的种子。**不出现课程、价格、微信。**

**自动欢迎语（新人进群触发·可设自动回复）**
```
欢迎进群🌸 这里是【XX年级娃英语·家长交流群】

进群先领三样（群公告置顶，直接下载）：
① 分级书单（按年级）
② 磨耳朵歌单/动画清单
③ 家庭英语启蒙路线图

群里每天分享一个能马上用的小点，娃英语上有啥卡的地方随时在群里问，我看到就回~

想知道自家娃现在大概到哪一步、下一步该练啥，可以扣「测评」两个字，我给娃做个免费的口语定位（要发娃录音的话，会先征得您同意，咱只做定位不打分吓人）
```

**群公告置顶（长期挂着）**
```
📌 新家长看这里
· 三份资料：见下方文件/链接，随时取
· 每天一个实用点，群里刷就行
· 想给娃做个【免费口语定位测评】：群里扣「测评」，我一对一给你安排
· 群里只聊娃的英语，不发广告，放心待着~
```

**要点**
- "扣『测评』"就是你的**群内口令承接机制**——把领资料的人顺到测评，不用你主动私聊。
- 欢迎语里"定位/看清楚娃在哪一步"是**诊断框架**，不是卖课钩子，家长零压力。

## 模块2 · 口令领取话术（笔记扣口令→进群→群内公开发资料·绝不私信发联系方式）

> 场景：家长在笔记评论区/私信扣了口令（比如"路线图""书单""KET"），被引导进了群。她进群后可能直接问"资料在哪""口令XX"。**回复一律群内公开发，绝不私信、绝不发微信号。**

**A. 家长进群后问"资料怎么领 / 我扣了XX"**
```
在啦~ 三份资料都在群公告置顶了（📌那条），点进去直接下载：
① 分级书单 ② 磨耳朵清单 ③ 启蒙路线图

@这位家长 你家娃几年级、现在用啥教材呀？我看看哪份对你最有用，顺手给你划个重点~
```
> 一句话完成三件事：给到资料（履约）+ 公开在群（合规）+ 反问信息（起对话）。

**B. 家长私信来要资料（被动回·不主动私发）**
```
资料我整理在家长群里啦，进群直接领👉[群二维码/群链接]
（进群后翻置顶就有，我也在群里，有问题随时问我~）
```
> 🔴 私信只做"引进群"这一件事，**不在私信里发文件、不发微信号**。把承接搬进群这个私域场，更安全也更好养。

**C. 家长在群里问"能加个微信吗 / 有没有vx"**
```
可以呀~ 你先在群里跟我说下娃的情况（年级/教材/最头疼哪块），
我给你做个免费口语定位，出了报告需要单独发你，到时候咱再互留个联系方式方便发文件，你看行不~
```
> 不秒发微信。**把加微后置到"要发测评报告"这个真实需要发文件的场景**——让家长觉得合理，也让平台看着自然（多轮对话后、有明确履约理由）。

## 模块3 · 引导测评话术（"领资料"顺滑过渡到"先给娃做个免费定位"）

> 家长领完资料通常会停。**别让她停**——顺势把她推到测评。核心是把测评说成"给娃定位、看清楚下一步"，不是"卖课前置流程"。

**A. 家长领完资料 / 冒泡问了个问题后，顺势引**
```
资料是通用的，但每个娃卡的点不一样~
要不我给你家娃做个【免费口语定位】？就是发一小段娃读英文/说英文的录音，
我帮你听听：发音、敢不敢开口、句子能不能连起来，然后告诉你现在到哪一步、下一步重点练啥。
不打分不排名，纯定位，你心里有个数。要发录音的话，你作为家长同意就行~
```

**B. 家长问"怎么测 / 测什么"**
```
特简单，两步：
1️⃣ 你先填个两分钟的小表（娃年级、用的教材、最头疼哪块、想达到啥），我好给你对着看；
2️⃣ 让娃读一小段（课本上一段就行）发我，30分钟内我给你一份定位报告。

报告里会写：现在的水平（客观描述）、观察到的1-2个点、接下来3条具体建议。
全程免费，就是帮你把娃的情况看清楚~
```
> intake表见 `私域承接落点SOP-0828.md` 落点4。**先填表再出报告** = 筛意向 + 收信息做个性化 + 让家长有沉没成本、不容易薅完就走。

**C. 家长犹豫要不要测**
```
不测也完全没关系哈，资料你先用着~
要是哪天想知道娃"到底卡在哪、该往哪使劲"，随时找我测，一直免费的，不催你~
```
> 给退路 = 降压力。**永远不催**，这是学管老师和销售的分水岭。

## 模块4 · 测评后1对1话术（拿到报告→点出娃卡在哪→给方案→引到试听/报课）

> 报告已发（模板见落点4）。**报告本身不推课**，客观定位。推进发生在报告后的这轮对话。先点问题、再给方案、最后才提"要不要真外教陪练一次"。
> **按家长意向分三档，各一套。** 怎么判断：看她回报告的反应——追问细节多、问"怎么练/有没有课"=高意向；说"我看看/先自己练"=观望；只回"谢谢"、不接话=低意向。

### 4.1 高意向家长（追问多、主动问怎么练/有没有课）
```
（先落地问题）
报告你看了哈~ 娃最明显的就是【开口这一环】——认得单词、也读得出来，
但一到"自己组句子说出来"就卡，句子短、爱停顿。这不是词汇问题，是"输出练得少"。

（给方案）
这块光靠刷题和APP补不上来，得有个真人一来一回地接话、逼他开口。
我们有真外教一对一，就是专门练"敢开口+把句子说完整"这一环，节奏跟着娃走，不是照本念。

（临门·真实体验课，不夸张）
要不先安排一节真外教体验课？让娃真跟外教聊15-20分钟，
你在旁边听，就知道娃开口是啥状态、外教怎么带他。体验完觉得对路咱再聊后面，不对路也没关系~
你看娃这周哪天方便，我去排外教时间。
```
> 高意向直接推**体验课**（比"报课"轻，但已是真外教真交付），并用"选时间"这个**具体动作**推进，不给"要不要"的开放犹豫。

### 4.2 观望家长（"我先看看 / 自己带带看 / 再考虑"）
```
可以呀，先自己带完全没问题~ 我把娃这阶段的重点给你说透，你在家先练：
【重点：每天让娃把课文对话大声复述一遍，练"把句子说完整"，比默写有用多了。】

你先按这个练两周，我也在群里，随时问我。
等你觉得"自己带到瓶颈了、需要有人一来一回接话了"，再找我加个真外教陪练试试，不急哈~
```
> 观望的**不推课，先给真价值 + 埋钩子**。给一个她能立刻做的建议（继续履约、加深信任），把"该找外教"的判断标准（"有人一来一回接话"）种给她。留在群里养，下次她自己会回来。

### 4.3 低意向家长（只回"谢谢"、不接话、看完就沉默）
```
不客气~ 报告你先收着，娃啥时候练英语能用得上。
群里每天有实用点，有啥问题随时冒泡问我，就当多个人帮你盯着娃英语这块~ 🌱
```
> 低意向**绝不追单**。留好印象 + 留在群里，靠日常内容长期养。转化不在这一次，在她持续看你三个月之后。硬推=直接流失。

## 模块5 · 异议处理（各一句·不硬怼·先接再引）

> 通用心法：**先认同她的顾虑（"确实/理解/你说得对"），再给一个降压的下一步。** 从不反驳家长。

| 家长说 | 你回（可直接复制） |
|---|---|
| **太贵了** | "确实一对一是笔投入，我特别理解~ 所以才建议先来一节体验课，让娃真开口、你亲眼看看值不值，觉得对路再聊，不合适一点压力没有。" |
| **再看看/我考虑一下** | "应该的，这种事是得想清楚~ 那你先按我给的重点在家带着，我在群里，等娃练到需要人陪着开口了再找我，不催你哈。" |
| **娃没时间/作业太多** | "太懂了，现在娃是真忙😮‍💨 所以我们才做一对一，一次20-30分钟、时间跟着你排，不占整块。你也可以先体验一节看看娃能不能挤得出来，挤不出咱就先放放。" |
| **线下更好/想找线下班** | "线下有线下的好，看娃习惯~ 不过线下班一个老师带十几个，娃真开口的时间其实很少；一对一的好处就是这半小时全是娃在说。你可以都试试，哪个娃开口多选哪个。" |
| **APP/自己教就行** | "APP练输入很好，磨耳朵认单词都靠它~ 但'把话说出来、有人接'这块APP给不了，娃容易卡在'会读不会说'。你先用APP带着，等卡住了再加个真人陪练补这一环就行。" |

> 🔴 每一句都不出现"提分/见效/包过"，全部落在"敢开口/娃真开口的时间/补上缺的那一环"。

## 模块6 · 报课转化临门一脚（合规不虚构稀缺）

> 用在**已上过体验课、反馈不错**的家长身上。不是在犹豫期硬逼。三种真实推力，按情况选一个用，**绝不编造**。

**A. 体验课后趁热收（最高转化时机）**
```
娃这节课状态我看到啦~ 【具体：一开始有点腼腆，后面能主动接外教的话了，这就是开口的感觉】。
这种状态得连着练才留得住，断了很快回去。
要不咱先上【体验/基础包】把节奏稳下来？我按娃今天这个情况帮你配同一个外教（娃熟悉、进得快）。
```

**B. 真实限时（只在真有活动时说·不虚构）**
```
这个月正好有个【新学员体验价/开学季优惠】，到X号（真实截止日）。
你要是本来就打算试，趁这个报能省一点；没想好也不用赶，优惠常有，别为省这点仓促决定哈~
```
> 🔴 括号里的截止日必须真实。宁可不说，也不编"最后一天"。"没想好不用赶"这句反而让家长更信你。

**C. 阶梯给选择（把"要不要报"换成"报哪个"）**
```
看娃现在的情况，我给你两个方向你挑：
· 想先稳住开口这股劲 → 【体验/基础包】，够练一段先看效果；
· 想系统跟一学期 → 【标准包】，一个外教带到底，更连贯也更划算。
你倾向哪个，我帮你把外教和时间都排好~
```
> 阶梯的作用是**把决策从"报不报"变成"报哪个"**，同时给真实价值差异（不是套路），家长选哪个都是往前一步。

**报课后立即做**
```
报名啦🎉 我这就把你拉进【学员群】，外教和第一节时间我排好发你。
后面娃每次课我都会跟你反馈状态，有啥随时找我~
```
> 交付即拉学员群（见 `wechat-community-sop.md` 学员内部群），把成交无缝转成留存。

## 附 · 归因登记（每条线索都记·否则白跑）

每聊一个家长，在飞书/表格记一行（复用落点5的表）：

| 日期 | 来源号/笔记 | 命中口令 | 进群 | 扣「测评」 | 出报告 | 意向档(高/观/低) | 体验课 | 报课 | 一娃去重ID |
|---|---|---|---|---|---|---|---|---|---|

- **一娃一号一微信去重**，防薅免费真外教测评。
- 每周看：哪个来源/母题带来的家长最容易走到报课 → 加量；只领资料不测评的来源 → 内容要改钩子。

## 一页速查（贴在手边）
```
进群 → 欢迎语埋"扣测评" → 领资料(群内公开·不发vx)
→ 引导测评(填表+录音·监护人同意) → 30分钟出定位报告(不打分)
→ 报告后分档聊: 高意向→推体验课选时间 / 观望→给建议埋钩子留群养 / 低意向→不追·留群养
→ 异议先认同再降压 → 体验课后趁热/真实限时/阶梯选择 收
→ 报课即拉学员群·持续反馈
全程: 90%给价值·从不催·合规不承诺·加微只在发报告时·每条线索记归因
```
