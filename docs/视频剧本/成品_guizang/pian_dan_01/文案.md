娃看了一年Peppa，英语还是没长进？

可能不是孩子问题，是动画选错了阶段🙋

我整理了一份0-10岁英语动画分级清单，照着这个顺序看，循序渐进不踩雷——

**Level 1·磨耳朵期（0-3岁）**
Cocomelon / Blippi / Little Baby Bum
→ 当背景音乐放就行，不用强迫开口

**Level 2·开口期（3-5岁）**
Peppa Pig / Bluey / Hey Duggee
→ 短句、慢语速、高重复，跟着模仿说，语感就来了

**Level 3·扩词期（5-7岁）**
Octonauts / Magic School Bus / Wild Kratts
→ 词汇量开始跳级，科学类词汇自然积累

**Level 4·章节书过渡（8岁+）**
Horrible Histories / Hilda / Avatar
→ 能听懂笑点、跟上剧情，说明听力真的到位了
