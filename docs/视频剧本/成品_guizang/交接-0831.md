## 出图脚本

| 脚本 | 用途 |
|------|------|
| `render_v3.py` | 奶油白系（片单/KET用） |
| `render_v2.py` | 深色封面+白色内页（旧版） |
| `render_themes.py` | 主题色样本生成 |

核心依赖：本机 Chrome `/Applications/Google Chrome.app/`，无需额外依赖。

运行：`python3 render_v3.py`，图输出到对应成品文件夹，自动用 Finder 打开。
