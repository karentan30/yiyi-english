## 二、按学段分组的内容地图（家长一看就知道"我娃这段看啥、报啥"）

### 🍼 启蒙 3-6 岁 —— 磨耳朵 + 自然拼读起步
**该看的母题**：启蒙方法类①②③ / 资源收藏类 / 每日打卡类(童谣) / 家庭教育情感类(正反馈)
**核心信息**：先磨耳朵别背字母 → 童谣/动画/绘本按难度进 → 自然拼读第一步
**接哪门课**：`免费试听+能力测评` → **30课包**(试水) 或 **80课包**(想认真启蒙一年)
**一句话给家长**："这个阶段不考试，先让娃'听得进、敢跟读'，我们外教从磨耳朵和拼读起步。"

### 📖 小学低 6-9 岁 —— 拼读解码 + 分级阅读起步 + 敢开口
**该看的母题**：课本同步原创类 / 每日打卡类 / 资源收藏类(牛津树/RAZ) / 舞台剧名著类(入门) / 生活英语短视频
**核心信息**：拼读见词能读 → 牛津树/RAZ怎么刷不浪费 → 课本内容用起来 → 日常场景开口
**接哪门课**：`免费测评` → **60课包**(每周2-3次稳定) 或 **80课包⭐**(全年系统)
**一句话给家长**："娃开始能拼读了，重点是分级阅读别刷废、把课本'说'出来，外教1对1补校内轮不到的开口。"

### 🎤 小学中高 9-12 岁 —— 开口表达 + 读写进阶 + 素养 + KET起步
**该看的母题**：观点痛点类 / 学习方法类 / 朗诵演讲类 / 用英语讲中国 / 英语演讲比赛 / 舞台剧名著类 / 排名榜单类 / 决策转化类 / KETPET数据分析(KET) / KET报名红黑榜(KET)
**核心信息**：破哑巴英语/伪流利 → 词根/影子跟读/精泛读 → 演讲戏剧练开口练逻辑 → KET(A2)是不是该上
**接哪门课**：`免费测评` → **80课包⭐**(主) ；有KET目标 → **160课包**(高频冲刺)
**一句话给家长**："娃分数够、开口弱，这段补'敢说会说'+读写方法；想冲KET/演讲赛，走高频外教1对1。"

### 🎓 初中 12-15 岁 —— 考级(PET) + 开口逻辑 + 输出
**该看的母题**：KETPET数据分析(PET) / KET报名红黑榜(PET) / 决策转化类(备考) / 观点痛点类 / 学习方法类 / 英语演讲比赛(即兴/逻辑) / 家庭教育情感类(青春期动力)
**核心信息**：PET(B1)难度与价值 → 备考路线&时间线 → 刷题不如开口 → 青春期不学怎么破
**接哪门课**：`免费测评` → **160课包**(备考+持续高强度) ；信心/动力问题先 **80课包**稳节奏
**一句话给家长**："初中是PET和输出关，别只刷题；用外教1对1把'说'和'考'一起带，青春期先修动力。"

> 🔴 学段接课红线：KET/PET相关内容统一接 **160课包（含KET/PET备考路径）**，但文案只说"完整备考路径/高频冲刺"，**不说"包过/一定拿分/保证录取"**。

## 三、标题增词建议（加"年龄/年级/学段"词让笔记更精准可搜）

家长在小红书搜索时高频带"几岁/几年级/幼升小/KET"等限定词——标题加学段词=**吃精准搜索流量 + 让家长秒对号**。建议改法（举例）：

1. **启蒙方法·自然拼读** —
   原：「自然拼读第一步不是背字母」→ 改：「**3-5岁**自然拼读第一步，别再让娃背字母了」

2. **资源收藏·绘本清单** —
   原：「0-8岁绘本按年龄挑」→ 已带岁数✅，可再细：「**0-3岁磨耳朵 / 4-6岁启蒙**绘本，按年龄别买错」

3. **每日打卡·跟读** —
   原：「第1天 My Day 跟读」→ 改：「**幼儿园-一年级**每日跟读第1天 My Day（磨耳朵打卡）」

4. **课本同步·词族** —
   原：「暑假提前会单词」→ 改：「**小学三年级**暑假预习：词族记忆法，别照念单词表」

5. **观点痛点·哑巴英语** —
   原：「娃能考高分却不敢开口」→ 改：「**小学中高年级**：分数95却开不了口，问题出在哪」

6. **英语演讲比赛** —
   原：「英语演讲比赛有哪些值得参加」→ 改：「**小学初中**英语演讲比赛怎么选（按含金量+适龄排）」

7. **KETPET数据** —
   原：「KET考120就过但别停在120」→ 改：「**5-6年级冲KET**：考120就过，但140才值这个证」

8. **KET报名红黑榜** —
   原：「KET/PET备考路线」→ 改：「**KET小学冲刺 / PET初中衔接**：备考路线+时间线一张图」

> 增词原则：①主段用"岁"（低龄）或"年级"（学龄）②考级内容绑"年级+级别"（如"5-6年级冲KET"）③**绝不**在标题写"包过/保过/必上名校"——违反合规红线。
