## 模块一 · 选题清单（真娃可拍的 10 个高传播选题）

> 每条标注"为什么高传播"。拍摄前先确认该素材**真实存在且已获监护人书面同意**。

| # | 选题 | 拍什么（真实素材） | 为什么高传播 |
|---|---|---|---|
| 1 | **英语演讲片段** | 娃在学校/机构/家里完整或半段英文演讲原声 | 有"完成度"和"临场感"，家长最有代入感（"我娃也能上台吗"）；真实台风比任何摆拍都可信 |
| 2 | **英语比赛现场** | 比赛候场/上场/评委反应的真实片段（**不虚构名次**） | 现场氛围自带紧张感和戏剧张力；"过程"比"结果"更打动人，且不夸大成绩不踩合规红线 |
| 3 | **英文配音 / 影视跟读** | 娃给动画片/绘本角色配音的真实录音 | 声音表现力强、可对比原声，趣味性高、完播率好；模仿门槛低，家长易转发"求同款方法" |
| 4 | **开口前 → 3 个月后对比** | 同一娃早期羞于开口的原始片段 + 近期流利片段 | "before/after"是母婴天花板级钩子；真实时间跨度=真实说服力，直接触发"我娃也想要这个变化" |
| 5 | **日常纠音瞬间** | 家长/外教纠正一个具体发音的真实互动（th、v、r 等） | 有"教学价值 + 真实感 + 反差萌"，评论区天然讨论"这个音我娃也读错"；最容易起互动 |
| 6 | **读绘本 / 分级读物** | 娃独立朗读一页真实绘本的原声 | 场景真实温馨、门槛低，家长看到"原来在家就能练"；可延展成书单引流 |
| 7 | **和外教连线** | 娃与真外教真实上课/连线的片段（外教同意出镜） | 真外教出镜=信任号核心资产；真实对话比广告可信 100 倍，直接展示"孩子和外教互动的样子" |
| 8 | **才艺展示（英文）** | 英文歌、英文小主持、英文情景剧等真实表演 | 才艺自带观赏性和"晒娃"传播力，情绪价值高、家长共鸣强 |
| 9 | **真实提问/踩坑复盘** | 家长真实遇到的启蒙难题 + 真实怎么解决的 | "同款焦虑"引强共鸣（不开口/畏难/坚持不下来）；真实经历=信任，评论区问答起量 |
| 10 | **一次真实的小挫败 + 怎么过来的** | 娃某次没读好/紧张哭了 + 后来的真实进步 | 反完美叙事最真实、最抗"炫娃"反感；"不完美的真实"比"样样第一"更让家长信任 |

> **选题优先级建议**：起号阶段主推 #4 对比、#5 纠音、#7 外教连线（信任转化最强）；有比赛/演讲真实素材时上 #1 #2 做高光；#9 #10 做人设厚度和评论互动。

## 模块二 · 3 个文案框架模板（真实素材套用 · 留【】占位）

> 【】=必须填真实信息，填不出=不发。所有框架**转化位统一**：评论区互动 → 主页进群 → 群内测评。

### 框架 A ·「娃的第 X 次英语演讲」

**适用素材**：#1 演讲、#2 比赛、#8 才艺

- **钩子（前 3 秒 / 标题）**（三选一）
  - "【X】岁的娃第【N】次上台讲英文，这次我没帮她改稿"
  - "她第一次演讲紧张到忘词，这是【N】个月后的样子"
  - "不是天赋型的娃，怎么敢开口讲英文的？"
- **正文结构**
  1. **真实起点**：娃现在【几岁】、学了【多久】、这是第【几】次【演讲/比赛/表演】——**只写真实数字**
  2. **真实过程**：这次准备中真实发生的一个细节（忘词/自己改了一句/紧张手抖）——**具体、不美化**
  3. **家长视角**：我作为妈妈真实的感受 + 一个真实的小方法（怎么陪练的）——**方法要真做过**
  4. **诚实边界**：不吹"第一名""最厉害"，可写"进步比结果重要""她敢开口我就满足了"
- **转化位（评论区置顶）**："在家陪练英语演讲的具体步骤，整理好放群里了，进群方式看主页～评论区聊聊你娃现在敢开口吗？"
- **封面建议**：真娃上台/手持稿子的真实照片（正脸需家长同意，或用背影/侧脸/局部）；标题压左上或底部，留白区放"第【N】次演讲｜【X】岁"

### 框架 B ·「开口前 → 3 个月后对比」

**适用素材**：#4 对比、#3 配音、#6 读绘本

- **钩子（前 3 秒 / 标题）**（三选一）
  - "同一个娃，左边是【X】月前，右边是现在（没报天价班）"
  - "从一句不敢说，到能给动画配音，我们只做了这【3】件事"
  - "【N】个月前她读绘本磕磕巴巴，现在……"
- **正文结构**
  1. **before 真实片段**：标注真实时间"【X 年 X 月】"，如实说当时的状态（不敢开口/发音卡壳）
  2. **after 真实片段**：标注"现在"，展示真实变化——**两段必须是同一个娃的真实录像**
  3. **中间做了什么**：真实、可复制的【2-3 件事】（每天几分钟/什么材料/怎么坚持）——**不夸大、不承诺"人人都能"**
  4. **诚实边界**："每个娃节奏不同""这是我们家的真实进度，不保证复制"——**明确不做效果承诺**
- **转化位（评论区置顶）**："这【3】件事的具体做法 + 用的材料清单放群里了，进群看主页；你娃现在卡在哪一步？评论区我看到都会回。"
- **封面建议**：左右分屏 before/after 真实截图 + 中间箭头；顶部留白放"【X】个月的真实变化"。**禁用 AI 换脸/美化娃的脸**

### 框架 C ·「一个真实的纠音瞬间」

**适用素材**：#5 纠音、#7 外教连线、#9 提问复盘

- **钩子（前 3 秒 / 标题）**（三选一）
  - "娃把【this】读成【dis】，外教这样纠了一次就对了"
  - "90% 中国娃都读错的这个音，看外教怎么教的"
  - "我娃这个发音错了半年，原来该这么纠"
- **正文结构**
  1. **真实场景**：什么时候、谁纠的（家长/真外教）、娃真实读错的那个词/音——**真实互动，非摆拍脚本**
  2. **具体怎么纠的**：外教/家长真实用的方法（口型/对比/小游戏）——**可复制、有教学价值**
  3. **娃的真实反应**：纠完之后娃真读对了/还没完全对——**如实呈现，不假装一次到位**
  4. **延伸价值**：这个音在哪些常见词里也会错（真实举例）
- **转化位（评论区置顶）**："常见错音清单 + 外教纠音示范整理在群里了，进群看主页～评论区留你娃最容易读错的词，我挑几个请外教示范。"
- **封面建议**：纠音瞬间的真实截图（外教/家长与娃互动画面，出镜均需同意）；大字压一个错音对比"【dis】❌ → 【this】✅"，留白区放引导语

## 模块三 · 配图 / 素材规格

### 真娃出镜拍摄建议

- **光线**：优先自然光（靠窗、白天）；避免逆光和昏黄顶灯。傍晚补一盏柔光/环形灯，别打出油光和硬阴影
- **背景**：干净、生活化（书桌、书架、绘本墙）；避免杂乱、避免出现门牌号/校牌/其他孩子可辨识的脸；避免品牌 logo 露出
- **时长**：单条素材原始拍 30 秒–3 分钟够剪；成片建议 15–60 秒（纠音/对比 15–30 秒完播最好，演讲/才艺可 30–60 秒）
- **收音**：安静环境近距离收音；英文原声是核心资产，别被环境噪音盖掉；必要时用手机+领夹麦
- **构图**：横竖都拍一份备用；小红书主竖屏 1080×1440 / 视频 1080×1920
- **隐私**：不露娃全名、学校、住址、班级；正脸出镜需监护人书面同意，未同意用背影/侧脸/局部（手、书本、口型特写）

### 封面排版建议

- **尺寸**：1080×1440（竖屏 3:4），**顶部或底部留出标题空位**
- **真实优先**：封面主图用**真娃真实拍摄照片**，禁 AI 换脸、禁美颜过度磨皮（真实感=信任）
- **标题**：一句钩子，大字、高对比、可读性第一；数字/对比符号（❌✅、→、第 N 次、X 个月）抓眼
- **一致性**：固定字体+固定色带做系列感，方便信任号识别；封面版式在 8 号间做差异化防限流
- **示意底图（仅限找不到真实场景图时）**：可用 AI **只出背景**（书桌/书架/暖色房间氛围），**不出文字、不出可辨识人脸**，且必须挂 **AIGC 标识**；娃永远用真实拍摄，绝不 AI 生成人物

## 模块四 · 合规清单（发布前逐条勾）

- [ ] **监护人书面同意**：每个出镜的娃，已取得监护人**书面**授权（可拍摄+可发布+可用于本账号获客）；留存授权记录
- [ ] **不虚构成绩**：演讲名次、比赛结果、证书、分数——**只写真实发生的**，没有的不编，不含糊暗示
- [ ] **真实反馈不夸大**：家长反馈、进步描述如实呈现；**不做效果承诺**（不写"包会""X 天流利""人人都行"）
- [ ] **明确个体差异**：涉及方法/进步的帖子，注明"每个孩子节奏不同，这是我们家的真实进度"
- [ ] **无微信号**：图上、正文、封面**永远不出现微信号/手机号**；联系方式只在群内私域发放
- [ ] **不主动私信导流**：只被动回主动私信来的人，绝不主动群发（防封号，见定稿文档第二节）
- [ ] **不用可辨识的他人孩子**：画面里不得出现未授权的、可辨识的其他孩子（同学、路人娃）；必要时打码/避开
- [ ] **外教出镜同意**：真外教出镜同样需其本人同意；不虚构外教资质/国籍/背景
- [ ] **AIGC 标识**：任何用到 AI 生成的示意底图，挂 AIGC 标识；人物一律真实拍摄不 AI 生成
- [ ] **AI 未编造**：全文无 AI 凭空编造的育儿经历/成绩/反馈；所有【】占位已填真实信息
- [ ] **隐私脱敏**：无娃全名、学校名、住址、班级、门牌等可定位信息
