七、总体出片流程（5条视频）

  3. 检查手机/相机设备 + 收音设备
  4. 准备 AI prompt，提前生成 B-roll 素材库

  • Day 3： 脚本 #1 + #5（需要高情感，早上光线最好时拍）
  • Day 4： 脚本 #2 + #4（逻辑脚本，对光线要求略低）

后期制作（Day 6-10）

  1. 素材导入剪映 + 自动字幕识别
  2. 各脚本人工校对字幕（对标质量评审表）
  3. 插入 B-roll + 音乐 + 音效
  4. 各脚本独立评审到 ≥目标分数
  5. 导出 1080P 竖版
