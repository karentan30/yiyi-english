## 三、学员内部群 SOP

### 进群条件
报名任意课包后，由老师手动拉入

### 群规
```
【一一英语学员群规】
1. 每周至少打卡1次（发30秒英语语音）
2. 可以发问题，老师每天回复
3. 相互鼓励，不嘲笑任何人的英语
4. 不发广告

### 每日运营

| 时间 | 内容 |
|------|------|

发语音+写出来更好哦 💪
打卡满4周可获得1节免费加课

```
