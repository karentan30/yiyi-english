## ① 收藏（拉新·把陌生家长圈进来）

**目的**：被陌生家长刷到 → 收藏/关注 → 主页访问
**看的指标**：收藏率、涨粉、主页访问（不是点赞）
**用什么内容**（都能零预算卡引擎出）：
- **免费资源合集**（片单/书单/歌单/App清单）← cici式·2月3.9万赞·家长爱囤
- **每日打卡系列**（每日一句/每日短文/磨耳朵）← 英语小短文10万粉
- **痛点避坑**（绘本别乱买/动画别乱刷/拼读搞反）← 评论互动高、算法推流
- 渠道：小红书 + 抖音 + 朋友圈（微信干货海报）
**→ 流向测评的钩子**：每条结尾「不知道娃到底什么水平？主页测一测」
**现有资产**：一诺妈号6条 / 微信干货海报30天 / 30天内容日历 ✅

## ② 测评（诊断·把流量变线索 + 裂变）

**目的**：完成测评 → 留资 → 晒裂变卡（回流①拉新）
**看的指标**：测评完成率、留资数、裂变卡分享数
**用什么**：测评 H5 `mylumee.cn/yiyi-ceping/`
- 20岛地图 / 竞技段位 / 剑桥·CEFR·词汇量·雅思托福（9把尺子可切）
- 段位成绩单 + 超前同龄对比（角落点睛）
- **🎤 真口语发音评测**（读一段→讯飞出准确度/流利度/完整度/声调分）← 最强差异化·家长测不了的·已接通出真分
- 预算分层路线 + 预测打分
- 裂变分享卡（家长晒 → 新家长进来测 → 闭环）
**→ 流向转化的钩子**：结果页「领取详细学习计划（免费）」留资 + 高预算档「预约外教免费试课」
**现有资产**：测评页已上线 ✅ · 口语发音评测已接讯飞、出真分 ✅（待真机验录音）

## ③ 转化（成交·把线索变客户）

**目的**：试课预约 → 报课
**看的指标**：进群数、试课预约、报课转化
**怎么走**（按测评结果分流）：
- **高预算家庭** → 测评直接推「欧美外教1v1免费试课」→ 试课 → 报课
- **中/低预算家庭** → 进群，用免费资源+内容日历养信任 → 看到娃进步 → 升级报课
**承接**：家长群 + 群内1对1 + 试课CTA（**私信只被动回，靠评论+主页进群**）
**现有资产**：一诺妈发布包承接话术 / 私域承接SOP ✅ ｜ **卡点=真实群+运营人（团队补）** 🔴

## ④ 定学习目标（留存·让家长留下来、续费、口碑）

**目的**：给孩子设定可视目标 → 每天推进 → 留存续费 + 自发晒
**看的指标**：连续打卡天数（10天=留存生死线）、续费率、口碑转介
**怎么做**（游戏化留存·调研验证）：
- 测评定位到「第X岛/某段位」→ 给明确下一目标（「3个月从第10岛闯到第13岛·冲KET」）
- 进群每天按**内容日历打卡**推进一格 → 攒**连续天数** + 解锁新岛
- 家长晒「已坚持XX天·闯到第X岛」← 转发率最高的成就类型 → 反哺①拉新
**现有资产**：30天分层内容日历 / 20岛目标体系 ✅ ｜ streak打卡后端闭环待验证后上
