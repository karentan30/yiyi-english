运营 SOP · 起号 + 承接（2026-08-28）

执行手册。运营团队每天照着做。内容不缺了，缺的是"让号活下来+把线索接住"——这份就是补它。

第一部分 · 起号冷启动（新号前30天）

阶段0：账号资料合规化 + 轻养号（第1-4天）

⚠️ 真正决定初始流量的是内容质量+账号垂直度，不是"养号天数"（官方多次辟谣养号玄学）。养号是辅助，别当核心。
- 【第一优先】账号资料合规化：昵称/简介禁用"包过/保过/约课/1对1/欧美外教/提分"等教培敏感词（会被压流量甚至封）。简介走"真实妈妈/教育观察"人设+价值+软钩子（如"主页有整理"）。
- 轻养号：每天正常刷"少儿英语/英语启蒙"、点赞收藏、每天关注3-5个同类号（别批量关注10+，批量关注=营销号特征）。
- 前几天不发内容，一机一号，别同IP同时登多号（不同手机/流量卡）。

阶段1：破0（第5-12天）

  • 第1篇必须是🌱破0篇：纯价值或纯情绪爆点，零钩子、零机构感、零导流（见成品库A1）
  • 一天最多1条（多条=作弊信号）
  • 前5篇都走"纯干货/纯情绪"，先把权重养起来，别碰转化款
  • 破0成功标准：单条曝光过500-1000 且互动率>3%（别用绝对赞数如"500赞"当标准——教育垂类互动本就低，会误判失败瞎改方向）

阶段2：加钩子（第13-30天）

  • 权重稳了（连续几篇曝光过千），开始发转化款，钩子放评论区置顶（不进正文）
  • 每条封面出2版A/B，48h看点击率，<8%的版式淘汰
  • 跑出3套可复制资产：过10%点击的封面模板 + 能拿私信的软钩子 + 进流量池的爆款结构
  • 跑出来了 → 才复制到下一批号

限流自检（每条发完必做·2025-2026可执行版）

出现任一信号=疑似限流（别用"搜标题搜不到"判断——新笔记本来就有搜索收录延迟）：
- 发布后1小时曝光<50 且长期不涨（正常新笔记1小时内至少几十上百初始推荐）
- 笔记详情页顶部有 "审核中/仅自己可见" 提示
- 后台"笔记数据"里曝光曲线发布即平线（不爬升）
- 同类内容别的号有量、你连续几篇都个位/两位数曝光

救号（疑似限流后）

  1. 【第一步·最关键】先自查并删/改掉违规笔记（留微信、明显导流、禁词）——不删源头，光养也救不回来
  2. 停发所有带钩子/导流内容
  3. 连发3-5条纯干货/纯情绪，养7-14天
  4. 期间正常互动，别再触发导流特征
  5. 权重恢复（有笔记重新有正常曝光）后，再谨慎恢复钩子

单号健康红线

  • 新号每天≤1条；成熟号每天≤2条
  • 同一句钩子话术别连用（轮换，见下）
  • 别在笔记正文/评论区裸露微信号（谐音也高危）

第二部分 · 评论区运营（全案ROI最高·配专职人）

自己笔记

  • 每条自评置顶埋钩子（钩子只放这里，正文干净）
  • 用小号在自己笔记下带节奏：问"哪家好""求歌单"制造从众——⚠️每条笔记最多2-3条小号评论（刷太多=平台打击的"虚假互动"）
  • 评论/私信30分钟内必回（写进考核）
  • 评论问题→下周选题：家长在评论区问什么，就是下周的选题

去别人笔记截流（专职1人蹲）

  • 目标帖：竞品避雷帖、差评帖、"外教课怎么选"、求组队帖
  • 话术：真实家长口吻+给价值，绝不硬广、绝不留机构名/微信

    示例："同款踩过坑😮‍💨 后来发现关键是外教得真欧美+用体系教材，不然就是陪聊。我家中教+欧美小班配着来，娃开口明显好转。姐妹按需别踩二次坑。"

  • 引导：让人主动来看主页/私信你（主动来最安全），不在评论区导流
  • 控频：一个号一天截流评论≤5条，别刷屏被判营销

第三部分 · 承接话术库（分段·可直接抄）

原则：能留小红书生态就别硬跳微信；主动来的用户最安全；话术软到平台看不出。

① 笔记/评论 → 进群或留资

  • "评论区扣1（或扣娃年龄），我私信你" ← 比"私信我"转化高3-5倍（动作轻+公开从众）
  • 笔记可直接挂小红书群二维码（群二维码平台不封，比外链安全）："想要资料/想约测评的进群领👇"

①+ 钩子话术变体库（⚠️必须轮换·同一句反复用会被判导流限流）

"进群/私信/免费1对1"是敏感词组合，评论区钩子只做意向筛选、别明写拉群动作，承接靠主页/私信自动回复。10+种变体轮用：
- "评论区打【歌单】/【300】/【路线】，我置顶发你"
- "想要这份清单的姐妹，扣个🌱"
- "娃几岁？我给你说下对应阶段"（用回复代替发资料）
- "同款困扰的扣'我也是'"
- "想知道娃到哪一步的，扣'看看'，我回你"
- "①还是②，你站哪个？扣数字"（站队款，互动高）
- 置顶自评埋钩子，正文永远干净

原则：评论区只"筛意向"，不写"进群/免费1对1/私信我"；把承接动作藏到主页简介和私信里。

② 私信 → 加微信（最脆一段·30分钟内回）

  • 别一上来要微信。先在小红书里给价值、建立信任：

    "看到你想给娃测评~ 先问下娃几年级、用的什么教材？我先帮你看看情况"

  • 铺垫后软引导——⚠️ 别在文字里出现"vx/微信"（私信风控敏感词）。让用户主动给：

    "测评安排我给你，方便留个联系方式吗？我把报告和时间发你"
    或："回复【测评】，我拉你进服务群，里面安排"

  • 加微动作后置：先在小红书/群里给价值、多轮互动后再加微，别一上来就要。加不上也没关系：测评尽量在小红书内完成（群里约/视频通话初测）。

③ 免费测评邀约（两层·防薅）

  • 先给第一层（AI/中教初测·零成本）：

    "先给娃做个免费口语初测吧——发一段娃读课文或自我介绍的录音，我给你出一份测评报告（水平+问题+建议）"

  • 意向强的再上第二层（真外教1对1）——⚠️ 不收诚意金（试听/测评收费=教培投诉重点），用非付费沉没成本锁名额：

    "看你娃挺有基础，可以约一次真外教1对1测评（半节试听）。约的话先提交娃的一段录音+填个预约表，锁定时段——主要是防放鸽子🙏"

  • ⚠️ 未成年信息合规：让家长发娃录音前必须一句确认——"录音仅用于测评分析，需要您作为监护人同意哈"（PIPL/未成年人保护法要求监护人明示同意）。
  • ⚠️ 稀缺要真实：别编"本周仅剩3个"（虚假稀缺=虚假宣传）。用真实开班进度，或"这个时段名额有限"这种不可证伪的软表达。
  • 一娃一号一微信只领1次真外教测评（归因去重防薅）

④ 防放鸽子（约到率）

  • 预约填表选时段（制造沉没成本）
  • 测评前 48h + 2h 两次提醒
  • 空降补位：有人放鸽子立刻补下一个

⑤ 测评 → 报课（临门一脚·先诊断不硬推）

  • 测评后先给诊断+个性化路线，把小班包装成"解决方案"：

    "娃现在敢读不敢说，缺的是同伴互动和实战场景。1V1菲教练发音够，但要敢开口上台，更适合欧美小班实战。"

  • 价格锚点（关键）——⚠️ 别编具体"市场价¥400+"数字（虚构原价=价格欺诈）：

    "1对1通常更贵，小班是几个孩子分摊外教成本，所以每人只要¥200，还多了同伴互动和上台机会。"

  • ⚠️ "欧美外教"处处红线：凡说"欧美外教"，实际排课必须是欧美母语外教，否则=虚假宣传。宣传口径严格等于履约。
  • 拼班逼单：

    "这个欧美小班已经3个娃了，还差2个开班，要占位吗？"

⑥ 续费触点（学管日常）

  • 每月给家长一份成长记录（AI陪练前后对比录音+复述视频+外教评语）=看得见的成果
  • 课时剩1/4时叠期末/考前活动
  • 同一小班家长绑小群（同学关系=续费护城河）
  • 流失预警：出勤降/AI工具使用归零/长期不回消息→学管主动介入

第四部分 · 日常运营节奏（跑通期·2个号）

时间 动作
每天 每号发0-1条（新号≤1）；评论/私信30min内回；截流帖≤5条
每周 填四段漏斗表（曝光→进群→约测评→转报课）；砍哑火、加爆款；评论问题转下周选题
每两周 封面/钩子A/B结果复盘，淘汰低CTR版式
阈值 点击率<8%=封面废；互动率<3%=内容废；连续3篇曝光<500=疑似限流→救号
