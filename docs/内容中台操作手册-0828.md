# 内容中台 · 操作手册（2026-08-28）

> 给谁：内容中台 1-2 人（教务/HR）。运营线（学管）不用看这份。
> 目标：一个人能把"出稿→出图→拼视频→交运营"整条生产线跑起来，$20 一个月花不完。

---

## 一、两条路线，按你会不会用终端选
### A线（简单·人人能上手·不用装任何东西）
用**网页版**，套 Prompt 出稿：
- 量活（批量出文案/对话）→ **DeepSeek 网页 或 豆包**（免费）
- 要质量/把关 → **Claude.ai 网页**（用你的$20 Pro）
- 出图 → **ComfyUI（本机）+ Canva 叠字**
- 拼视频 → **剪映**
**大部分人走A线就够，$20 基本不动。**

### B线（进阶·会用终端的人·效率翻倍）
用 **Claude Code**（终端里的 Claude），优势是能**读整个文件夹、一次出几十条直接写成文件、跑 ComfyUI 脚本**：
- 打开"终端"App → 输入 `claude` 回车 → 进入
- 让它读 `~/projects/yiyi-english/docs/` 里的 Prompt 和手册，直接批量生成并存文件
- 省的是"逐条复制粘贴"的时间

## 二、日常生产流水线（5步）
| 步 | 做什么 | 用什么 | 花钱 |

## 三、什么时候用 Claude（$20）、什么时候用免费的
**用免费模型（DeepSeek/豆包/Ollama）**：
- 批量出笔记文案、对话、标签——量活全甩给它

**用 Claude（$20 Pro）**——只在这4件：
1. **母题策划**（想选题、想爆款角度）
2. **合规审核**（学生/免费模型出的稿，发给运营前让 Claude 过一遍红线）
3. **难改的重写**（免费模型写得平的，让 Claude 提升）
4. **B线自动化**（读文件、批量出稿写文件、跑脚本）

**永远不用花钱的**：出图（ComfyUI）、配音（剪映/edge-tts）、拼视频（剪映）

---

## 四、$20 省钱守则（贴墙上）
1. 量活先问免费模型，Claude 不干量活
2. Claude 里**用 Sonnet 不用 Opus**（文案不需要 Opus）
3. **一个 Prompt 出 10-20 条**，别一条条聊
4. 图/视频/配音**永远本机免费**，不碰 API
5. $20 只花在"策划+审核+难改+自动化"——一个月花不完

## 五、ComfyUI 出图（简版步骤）
1. 打开终端，进 ComfyUI 目录，启动（`venv/bin/python main.py`），浏览器开 `localhost:8188`
2. 从《ComfyUI出图prompt》复制对应 prompt（封面底图/头像/情绪封面）
3. 填负面词、尺寸（封面1080×1440 / 头像1024×1024），**一次出4张选最好**
4. 底图导入 **Canva** → 叠中文大标题（标题公式：数字+反差+锚点）
5. ⚠️ 自评<8分自己重跑；真娃/真外教用真实授权素材，别用AI假人配"我家娃"

## 六、发给运营前·合规自查（30秒过一遍）
- [ ] 没承诺效果（"就敢说了"→"明显更愿意开口"）
- [ ] 没编数据（市场价/多少所学校）
- [ ] 没贬损菲教
- [ ] 正文干净、没"扣1我发你"、没微信号
- [ ] 评论钩子换了写法（没全是"扣测评进群"）
- [ ] 封面不是思维导图/对比表（那些放内页）
- [ ] AI图没配"我家娃"；真娃真外教已授权

全绿才交运营。有一条不确定 → 丢给 Claude 审一遍。
