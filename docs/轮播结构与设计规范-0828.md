# 图文轮播 · 结构与设计规范（2026-08-28）

> 首图决定点击，后面几张决定收藏和转化。完整轮播 = **强首图 + 内页交付价值 + 尾图软引导**。
> 设计方向（Karen定）：**字大、占满屏、一句话就是一张图**。别做线框/PPT感。

---

## 一、设计规范（所有卡通用）
- **首图必须大字占满屏**：主标题 100-160px，占据画面主体（参考`金句卡.png`/`数字卡.png`）
- **有质感**：渐变背景+柔和阴影+高亮笔触+装饰(引号/✨)，别纯色平铺
- **配色**：深色底(痛点/金句) 或 暖色底(数字/清单)，避免大红大蓝原色
- **高清**：渲染用 `--force-device-scale-factor=2`（2倍图）
- **每张≤2个信息**：一张卡只讲一件事，别塞满
- 模板都在 `card-templates/`，改内容→Chrome无头渲染

## 二、三种轮播结构（按内容类型选）

### 结构A · 清单/资源型（涨粉·高收藏）例：磨耳朵歌单
1. **首图**：数字冲击大字（"8首歌 = 记住200词"）
2. 内页2-7：**一张一个条目**（歌名+学什么词），大字清晰
3. **尾图**：软引导"完整版评论区打【歌单】" + 关注理由
> 内页别一张塞8条，拆成一条一张，划得动、看得爽、收藏率高

### 结构B · 对比/测评型（决策·转化）例：RAZ vs 牛津树
1. **首图**：金句大字（"选错多走一年弯路"）
2. 内页2：左右对比总览（对比卡）
3. 内页3-5：**逐维度对比**（分级/侧重/适合，一维一张大字）
4. 内页6：**结论**——"这样的娃选A，那样的娃选B"
5. **尾图**：软引导"不确定？往下看/主页有测评"（无导流词）

### 结构C · 故事/痛点型（信任·真人IP）例：AI对冲
1. **首图**：痛点金句（"跟AI练半年，见真人还是不敢开口"）
2. 内页2：**场景还原**（当时发生了什么，真实感）
3. 内页3：**转折/我发现的**（原来缺"真人对话"）
4. 内页4：**我的做法**（AI日常+一周1-2次真外教）
5. 内页5：**变化**（娃现在敢开口了，真实不吹）
6. **尾图**：软引导"你娃也这样？评论区聊" + 主页承接

## 三、尾图铁律（承接不导流）
- 尾图只做：**软引导站内动作**（评论区打【X】/主页有整理/关注理由）
- **绝不出现**：私信/微信/vx/1对1/免费测评/约课/欧美外教（图像OCR会抓，限流）
- 真正的转化动作全在评论区置顶+主页+私信三层（见《私域承接落点SOP》）

## 四、生产口径
- 首图/尾图：HTML大字卡（`金句卡/数字卡`模板改）或真实素材+Canva叠字
- 内页信息卡：HTML卡（对比/清单/路线）或图库场景+大字
- 视频版：同一套图+配音+字幕→剪映拼（免费不烧显卡）
- 一个母题 = 一套轮播（首图+内页+尾图）+ 一条视频（一鱼两吃）
