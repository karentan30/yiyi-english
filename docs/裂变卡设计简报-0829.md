# YiYi 少儿英语测评「裂变分享卡」设计简报

> 对标教育机构 / 知识付费成功裂变海报套路，供设计直接照抄。
> 场景：孩子测完出「段位成绩单」→ 生成一张海报 → 家长发小红书 / 朋友圈 → 拉更多家长来测。
> 日期：2026-08-29

---

## 一、核心结论（先看这 3 条）

1. **主标题不写「课程卖点」，写「孩子的结果 + 家长的行动价值」。** 把孩子刚测出的段位/超越百分比做成视觉锤（占卡片高度 1/5，最大字号），标题是普适痛点 + 免费钩子的组合，让人不点开图就懂——这是转发率第一杠杆。

2. **裂变机制选「专属海报 + 好友扫码达标解锁」，别选纯集赞。** 家长晒的是「我孩子的成绩单」（有面子、愿意晒），钩子是「3 位好友扫码测评，解锁孩子专属提升资料包 / 1 节外教体验课」。晒成绩单是自发动机，福利是加速器，两者叠加。

3. **视觉走「成绩单/证书」质感，不走「广告 DM」质感。** 低饱和莫兰迪配色 + 大量留白 + 段位徽章/盾牌图形 + CEFR/剑桥 KET 对标轴，让家长觉得体面、像官方认证。去掉所有「立即抢购/仅限今天」的红底黄字促销感——那是家长不愿晒的死因。

---

## 二、主标题文案公式（8 个可直接套用模板）

裂变海报信息优先级：**主标题 > 副标题 = 成绩展示区 > 二维码 > 行动引导 > 卖点 = 福利区**。主标题是最大卖点，字号尽可能大。

四大底层公式（源自 woshipm 裂变海报套路）：**获得型 / 速成型 / 权威型 / 痛点型**。套到「英语测评 + 段位」：

| # | 类型 | 模板 | 示例文案 |
|---|------|------|----------|
| 1 | 获得型 | 数字结果 + 超越感 | **「我家娃英语测出 XX 段，超过全国 87% 同龄孩子」** |
| 2 | 获得型 | 免费福利前置 | **「免费！3 分钟测出孩子英语真实段位（附提升方案）」** |
| 3 | 权威对标 | 段位 + CEFR/剑桥锚点 | **「XX 段 ≈ 剑桥 KET 水平，你家娃到哪一级了？」** |
| 4 | 速成型 | 时间少 + 结果清晰 | **「3 分钟测评，看清孩子英语的 6 个能力维度」** |
| 5 | 痛点型 | 恐惧问题 + 解决方案 | **「不知道孩子英语算不算好？一测便知，免费出诊断报告」** |
| 6 | 从众型 | 已测人数 + 社会认同 | **「12 万家长已给孩子测过段位，你还在盲目报班吗？」** |
| 7 | 悬念型 | 专属 + 未知 | **「孩子的英语段位揭晓了 👉 你敢猜是第几段吗？」** |
| 8 | 互惠型 | 转发 = 得福利 | **「测完转发，免费领孩子专属提升资料包」** |

**照抄要点**
- 主标题只用一句、10-16 字，字号占卡片高度 1/5，无衬线粗体。
- 数字必出现（段位数 / 超越百分比 / 3 分钟 / 万人）——数字是可信度和吸引力的锚。
- 副标题一行，补充主标题：写「免费出诊断报告 · 6 大维度 · 对标 CEFR」。
- 恐惧感要「适中」：点「不知道孩子水平」够了，别写「不测就落后」制造焦虑（家长反感、不愿晒）。

## 三、福利钩子机制（3 种，按适配度排序）

裂变通用逻辑：**用户转发/好友扫码 → 系统捕获 → 给转发者福利**。

### 机制 A：专属成绩单海报 + 好友达标解锁（首选）
- 家长测完自动生成「孩子专属段位成绩单卡」（带娃昵称/头像/段位）。
- 卡上写：**「邀 3 位家长扫码测评，解锁孩子专属《XX 段提升资料包》」**。
- 好友扫码测评即计数，达标后推送资料包 / 解锁完整报告 / 1 节外教体验课。
- **为什么首选**：晒成绩单本身是家长自发的炫耀动机（有面子），福利只是加速，不靠硬集赞，去广告感最强。

### 机制 B：低价体验课 + 分销返现
- 9.9 元外教体验课做钩子，家长分享专属码，每邀 1 人成交返现/返课时。
- 适合已有付费课的转化闭环；斑马/宝宝玩英语均用此路径。
- **注意**：返现有诱导分享合规风险，福利话术走「感谢好友一起学」不走「赚钱」。

### 机制 C：阶梯集赞/邀请解锁（辅助）
- 「集 X 位好友测评」阶梯式解锁不同福利（3 人得资料包 / 5 人得测评详批 / 8 人得体验课）。
- 阶梯给持续转发动力，但纯集赞广告感偏重，建议只作为 A 的进度可视化，不单独主打。

**统一红线**：面向未成年，福利话术只对家长；不做「不转不给报告」的硬门槛（留自发晒动机 + 合规）。

## 四、版式骨架（3 套，文字描述布局，可直接照抄）

竖版 9:16（朋友圈/小红书友好）。三套按「炫耀感 / 权威感 / 悬念感」分。

### 骨架 1：成绩单证书式（主推 · 最像官方认证，最愿晒）
```
┌─────────────────────────┐
│  [顶部] YiYi 品牌 logo + 「英语能力测评报告」小字   ← 5%
│                                                    │
│  [主视觉] 大号段位徽章/盾牌 + 段位名              │
│           「XX 段 · 超过 87% 同龄孩子」            ← 25%（视觉锤）
│                                                    │
│  [专属信息] 娃昵称/头像 · 测评日期                ← 8%
│                                                    │
│  [能力雷达] 6 维能力小雷达图/条形                 ← 20%
│           听/说/读/词汇/语法/表达                  │
│                                                    │
│  [对标轴] 段位 ⟷ CEFR ⟷ 剑桥 KET 横向对照条      ← 12%
│                                                    │
│  [福利说明] 「邀 3 位家长测评，解锁专属提升包」    ← 10%
│                                                    │
│  [二维码] 右下角，配「扫码免费测孩子段位」        ← 15%
│  [信任背书] 底部一行：外教团队 · 12 万家庭已测    ← 5%
└─────────────────────────┘
```

### 骨架 2：结果冲击式（炫耀/从众感最强，适合小红书）
```
┌─────────────────────────┐
│  [超大主标题] 「我家娃测出 XX 段，超 87% 同龄人」  ← 22%
│  [副标题] 一行：免费出诊断 · 对标剑桥 KET          ← 6%
│  [大插画/照片] 孩子学习卡通场景（去实拍隐私）      ← 30%
│  [3 个关键数字块] 段位 / 超越% / 测试时长          ← 15%
│  [福利条] 描边小卡：转发解锁提升资料包             ← 10%
│  [二维码 + CTA] 底部居中「扫码测你家娃」           ← 12%
│  [背书] 最底一行小字：外教团队 · 12 万+ 家庭       ← 5%
└─────────────────────────┘
```

### 骨架 3：悬念揭晓式（互动钩子最强，评论区互动率高）
```
┌─────────────────────────┐
│  [主标题] 「孩子的英语段位揭晓 👉 你敢猜第几段？」 ← 20%
│  [段位阶梯图] 竖向段位阶梯，高亮孩子所在段        ← 30%
│  [一句人话解读] 「XX 段 = 能和外教做简单日常对话」← 12%
│  [对标轴] 段位 ⟷ CEFR ⟷ 剑桥 横条                 ← 10%
│  [福利] 「测完转发，免费领同段位提升清单」        ← 10%
│  [二维码 + CTA] 「3 分钟，免费测」                 ← 13%
│  [背书] 底部一行                                   ← 5%
└─────────────────────────┘
```

**三套通用排布铁律**
- 主标题永远最大、最上/最先看到；二维码永远在下方固定位（右下或居中）配一句 CTA。
- 相关元素成组、组间留白 → 自然分区不杂乱。
- 一屏一信息重心，别堆超过 5 个模块。

## 五、信任背书怎么放

背书是「权威型」套路的落点，放在成绩权威性和二维码附近，别喧宾夺主。

| 背书类型 | 呈现方式 | 放哪 |
|----------|----------|------|
| **权威对标** | 「段位 ⟷ CEFR ⟷ 剑桥 KET/YLE」横向对照轴，把自家段位锚到国际标准 | 成绩区正下方（最重要，转化家长认知） |
| **能力可视化** | 剑桥用「盾牌 shield」表现各技能水平——照抄，用徽章/盾牌图标做段位，比数字更权威更好看 | 主视觉徽章 |
| **服务规模** | 「12 万+ 家庭已测评」「已生成 XX 万份报告」——从众社会认同 | 底部背书行 / 数字块 |
| **师资资质** | 「北美/剑桥认证外教团队测评标准」一行字 + 小图标 | 底部背书行 |
| **报告权威感** | 顶部加「英语能力测评报告」标题 + 品牌 logo，整体做成「证书」感 | 卡片顶部 |

**要点**：CEFR/剑桥对标是本卡最强背书——它把「一个不知名 App 的段位」变成「国际认可的水平坐标」，家长敢晒、愿信。对照轴一定要做、要清晰。

## 六、视觉 Do / Don't（减负增美感，去广告感）

### ✅ Do
- **低饱和莫兰迪/柔和配色**：奶油白、雾霾蓝、豆沙粉、淡橄榄绿——优雅内敛，像高端教育品牌，不像地推传单。
- **大量留白**：主视觉突出、模块间留呼吸感；留白 = 高级感 + 可读性 + 优先级清晰。
- **单/双色主调**：全卡 2-3 个颜色封顶，一个主色 + 一个强调色。
- **徽章/盾牌/雷达图等图形化数据**：把段位、能力做成可视化图形，比纯文字体面、可信、好看。
- **无衬线粗体做标题**，正文字号克制、层级分明（大标题/中副标/小背书三级）。
- **证书/成绩单版式感**：顶部品牌 + 标题、中部成绩、底部背书，规整对称像官方文件。
- **插画优先于实拍**：卡通学习场景规避孩子肖像隐私，也更统一好看。

### ❌ Don't
- **别用红底黄字/爆炸贴/「限时」「立即抢」促销感**——家长最不愿晒的就是这个。福利用描边小卡低调呈现。
- **别堆超过 5 个信息模块**，别塞满不留白（杂乱 = 廉价 = 不晒）。
- **别用超过 3 种颜色 + 多种字体**混排。
- **别制造过度焦虑**（「不测就落后」「别人家孩子已经…」），恐惧适中即可，过度反感。
- **别把二维码做小或藏起来**——它是裂变闭环终点，要清晰 + 配一句 CTA。
- **别露真实孩子照片/全名**——隐私 + 合规，用昵称 + 头像插画。
- **别写课程价格/长段卖点文案**——这是「分享卡」不是「落地页」，信息越少越愿转。
