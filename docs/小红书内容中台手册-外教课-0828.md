# 外教课 · 小红书/多平台内容中台手册 v1（2026-08-28）

> 目的：把选题、公式、钩子、红线、分工、分销全部固化，7 个人照着填就能铺号，不用每次想。
> 一句话战略：**内容负责"信任+需求"，私域负责"成交"；1V1 引流走量，小班/演讲课赚利润。**

---

## 0. 一页总纲

### 转化漏斗三层（内容按此分层，别指望顶层直接成交）
- **L1 认知层（科普型）**：制造"该报课"的需求。流量大、SEO稳、转化慢。
- **L2 决策层（测评对比型）**：家长要报了在选谁。强意向、中高转化。**必须中立人设**。
- **L3 转化层（体验+钩子型）**：临门一脚，**真正带来报课**。

### 核心机制
```
爆款母题 → 一套母素材 → 拆5种形态铺全平台（一鱼多吃）
内容挂"免费口语测评"钩子 → 评论/私信 → 企微 → 试听 → 报课（小班/演讲）
```
小红书笔记别想直接成交（平台压外链），全部引到私域。

### 商业账（为什么主推小班/演讲）
| | 收入 | 外教成本 | 单节毛利 | 每生毛利 |
|---|---|---|---|---|
| 1V1（现状） | ¥80-120 | 菲教¥50-70 | ¥30-60 | ¥40 |
| 小班演讲课(5人×¥200) | ¥1000 | 欧美¥250 | ¥750 | ¥150 |
→ 小班每生毛利 3-4 倍且能上更好外教。1V1=获客钩子，别砸钱投流；利润靠升级小班。

## 1. 五大内容赛道 + 母题库

### 赛道A｜教材/路线规划（L1-L2，收藏型，数字人口播铺量）
- 国际路线英语全规划（幼儿园→小学→初高中，一图讲清）
- 单教材拆解：Reach Higher / Unlock / Great Writing / Reading Explorer / Keynote / Wordly Wise / My Pals math
- 落课钩子：讲某教材 → "我们开了对应精读小班，可试听"

### 赛道B｜教材/机构对比测评（L2，争议型·高评论，**中立人设**）
- 教材对比：国际学校教材 vs 体制内 / RAZ vs 牛津树 / 原版 vs 引进版
- 机构对比、哪家外教课好、好评差评榜、课程测评、外教价格
- 中式英语 vs 外教带的 / 菲教 vs 英美外教
- ⚠️ 机构自发=王婆卖瓜+拉踩风险 → 用"第三方测评/家长真实体验"人设，建议开独立测评号（鱼Sir路径）

### 赛道C｜英文歌/儿歌学单词（L1，资源型，稳定收藏）
- 100首英文歌记单词 / 6首歌搞定6000词（速成数字承诺）
- 听儿歌学单词 EP1-52（每周一首：Baby Shark→family words）
- 怎么记单词（词根词缀/联想/图像记忆法）
- 落课钩子：外教带记单词，一组10个 → 试听

### 赛道D｜外教领读/纠音/口语（L1-L3，长尾+信任，展示真外教）
- 外教领读一单元 + 纠中式发音 + 拆5个单词（**别纯朗读，纯朗读不爆+版权坑**）
- 每节课和外教记X个单词（效果量化，⚠️别写死承诺"保证记住"）
- 外教课怎么上才值 / 外教课聊什么

### 赛道E｜演讲课成果 + 真外教/真娃（L3，信任型，转化+转发）
- 内向娃3个月敢全英文上台演讲了（前后对比=爆款王）
- 8岁娃的英文TED演讲，全场鼓掌
- 英文演讲开场5个万能句（清单收藏）
- 真外教出镜自我介绍（Josh模式，已验证火）

### 必做对冲/科普（L1，制造需求）
- **AI搭子 vs 真外教**（1.1万赞那条是威胁）：AI能陪练但纠不了发音、给不了真实互动
- 为什么要找外教 / 有必要找外教吗 / 语言关键期（制造紧迫感，⚠️别过度贩卖焦虑）

## 2. 标题公式 + 标签

### 万能标题公式
**数字/权威 + 无痛/速成利益 + 具体锚点（教材名/歌名/体系名）**
- 例：美国1000所小学在用的《Reach Higher》怎么学
- 例：学会这6首歌，立马搞定6000词
- 正文结构（三句极短）：痛点问句 → 我给解法/资源 → 无痛结果

### 标签库（全内容词，不带机构名，抗限流）
- 大流量：#少儿英语 #英语启蒙 #英文歌曲 #鸡娃
- 精准：#英语启蒙儿歌 #听歌学英语 #原版教材 #自然拼读 #分级阅读
- 场景：#国际学校 #国际路线 #双语学校 #ket #pet #幼小衔接 #零基础学英语
- 热点/工具：#趣味记单词打卡 #英语笔记（蹭工具流量）
- 教材词：#reachhigher #unlock #牛津树 #raz

## 3. 转化钩子（L3，真正引到报课）★

1. **免费口语测评（王牌）**：每条内容底部挂"想知道娃水平？私信领免费口语测评+提升建议"。谁都想知道自家娃水平。
2. **求组队/拼班**：宝妈口吻发"坐标XX，求组队Reach Higher外教小班，已有2娃" → 直接凑班（解决满班率命门）+ 精准获客。评论区接真实求组队家长。
3. **课程转卖挖墙脚**：监控"外教课转让"帖=对别家不满/要退课的精准家长 → 私信"接课/低价试听"，专挖竞品墙角。
4. **试听体验 + 效果对比**：真娃前后对比，信任转化。

## 5. 内容生产 SOP

### 母题→多形态（一鱼五吃）
一个母题 → 母素材(选题+文案+9图+配音) →
① 小红书图文轮播 ② 小红书配音视频 ③ 抖音图文轮播 ④ 抖音配音视频 ⑤ 视频号视频
→ 每周只需 5-8 个爆款母题，不是几十个原创。

### 抄爆款：抄套路不抄素材
- ✅ 抄：选题角度、标题公式、封面版式结构、内容框架、标签组合
- ⚠️ 改造：别人的信息图版式 → ChatGPT/Canva 重新生成成自己的（原创）
- ❌ 别搬：别人的原图、原文案、别人拍的照片、别人做的单词卡（侵权+图片查重判搬运号）
- 流程：截图存爆款 → 提炼结构 → ChatGPT重生成封面 → 填自己内容 → 挂测评钩子 → 7人各改一版发不同号

### 同内容多号发·最低差异化（保命，否则判重限流）
换封面 / 换标题 / 换开头3秒 / 换BGM / 微调裁剪 / 错峰发 + 养号+设备IP隔离

## 6. 红线清单

1. **合规底线**：学科英语不承诺"提分/包过/保证记住X词"（广告法）；不制造过度教育焦虑。
2. **版权**：教材封面/别人原图不直接搬，自拍或重做。
3. **国际学校关键词**：可用品类词(国际学校/IB/AP)；具体学校名只做信息型内容，**不做背书承诺/拉踩**。
4. **中立人设**：赛道B(哪家好/差评榜/机构对比)用独立测评号，别品牌号硬发。
5. **数字人**：不假冒外教；挂AIGC标识；不整号纯数字人。
6. **分销**：**只做一级分销**，二级以上=涉嫌传销违法。
7. **减脂式AI假音**：英文内容不用AI假音冒充外教。

## 7. 分销商模型（招人卖课给分成）

- **谁做**：宝妈团长/KOC、学员家长(老带新)、异业(绘本馆/母婴/培训)、博主带货
- **机制**：专属推荐码/海报/链接 → 成交归因 → 结算分成（教育课程佣金常见20-30%，高毛利小班课有空间）
- **老带新裂变**：双向奖励（推荐人得现金/课时，新人得试听/折扣）
- ⚠️ **只做一级分销**（法律红线）
- **技术前提**：推荐码归因系统（专属链接/企微打标），否则算不清

## 8. GEO / AI搜索（DeepSeek/豆包被推荐）——诚实版

- 值得做，但**是长期慢功夫，不是买码**。⚠️ 现在没有正规"付费买AI搜索推荐位"渠道，卖"包上豆包推荐/推荐码"的大概率是骗局。
- 真正move GEO的：
  1. 全网内容密度（小红书/知乎/公众号/官网都提到你的品牌+关键词）
  2. 第三方提及/测评/口碑（别人提你 > 自己夸）
  3. 知乎/官网做"少儿英语外教怎么选"FAQ式权威内容（AI爱爬取），自然植入品牌
  4. 结构化问答格式
- **动作**：现在就去 DeepSeek/豆包 问"少儿英语外教哪家好""XX(品牌)怎么样"记录现状，每月复测。
